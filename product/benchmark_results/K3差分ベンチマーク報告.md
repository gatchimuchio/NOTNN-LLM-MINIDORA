# MINIDORA対K3 差分ベンチマーク報告

**測定日：2026-08-18**  
**言語：日本語**  
**判定：`BENCHMARK_COMPLETED_WITH_DIFFERENCES`**

## 1. 比較境界

動的ベンチのK3側は、実Kimi K3のweight、API、2.8T規模、104B活性、multimodal、1M contextを実行したものではない。

固定した公開source：

```text
repository  MoonshotAI/Kimi-K3
commit      3cb39dfd32e51c3328e2e4b4af21341247d06c43
tree        fc92b6c233e751161a2c532b5753695c5789bccc
```

動的比較対象は、K3公開構造から次を抽出したin-memory非ニューラル射影版である。

- KDA相当：`RETAIN / DELTA_WRITE`選択状態
- Attention Residuals相当：過去stageの内容依存選択
- Stable LatentMoE相当：入力依存expert routing
- MOPD相当：`low / medium / high / max`計算予算

MINIDORA側は製品E2Eとして次を含む。

- SQLite WAL永続化
- session状態更新
- BM25／日本語n-gram検索
- Horn型規則推論
- HDS採否
- 日本語結果面
- request単位7段監査hash chain

したがって速度差は、アルゴリズム差だけでなく責任範囲差を含む。

## 3. 性能結果

300反復の温間逐次測定。

| 指標 | MINIDORA製品E2E | K3構造射影核 |
|---|---:|---:|
| 中央値 | 7.417 ms | 0.055 ms |
| p95 | 12.229 ms | 0.068 ms |
| 逐次QPS | 124.4 | 17,281.2 |

速度比だけを計算すると、射影核は中央値で約135倍軽い。しかしこれは実K3の速度ではない。K3射影側にSQLite、監査鎖、API、永続session、管理境界がないため、製品性能順位には使えない。

## 4. 境界課題

| 境界 | MINIDORA | K3構造射影版 |
|---|---|---|
| low深度 | SUSPEND | SUSPEND |
| high深度 | PASS | PASS |
| 矛盾事実 | SUSPEND | SUSPEND |
| 命令注入文書 | **FAIL** | SUSPEND |
| 会話状態継続 | PASS | PASS |

最も重要な差は命令注入文書である。

```text
K3構造射影版
候補の証拠不足・危険未確定
→ SUSPEND

MINIDORA
外部文書命令をhazardとして分類
→ HDSが出力権限を拒否
→ FAIL
```

これはMINIDORAが、汎用生成能力よりも製品統治境界を優先した結果である。

## 5. 構造差

### K3

```text
学習済み汎用表現
× 時間選択
× 深さ選択
× expert選択
× 計算予算選択
```

強み：

- open-domain汎用表現
- multimodal
- 長大context

- 自然言語生成品質

### MINIDORA

```text
明示文書・事実・規則
× lexical参照
× 直列規則合成
× HDS権限
× 永続監査
```

強み：

- 回答根拠の特定
- 未知・矛盾・危険の状態分離
- 決定的再現
- SQLite正本
- 監査hash chain
- CPUのみの低資源運用
- 管理可能な事実・規則

## 6. 差分結論

```text
K3
= 能力を大量に保持し、必要な計算経路を選ぶ汎用生成系

MINIDORA
= 許可された知識・規則だけを用い、HDSが最終権限を持つ根拠拘束系
```

両者は同じ競技の大小関係ではない。

- K3が上位：知識量、自由生成、multimodal、open-domain、長文汎用性
- MINIDORAが上位：根拠拘束、失敗状態、監査再現、統治、低資源性
- 同等だった局所範囲：構造化事実、多段規則、未知、会話状態
