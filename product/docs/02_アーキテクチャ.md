# アーキテクチャ

## 固定核

HDS Gateは全要求へ必ず適用し、証拠、矛盾、未知、危険、confidenceを検査する。

## 選択層

- 時間：sessionの`last_entity / last_answer / last_intent`
- 文脈：BM25と日本語文字n-gramによるpassage選択
- 深さ：effortに応じた規則round数
- 幅：direct fact、rule、retrieval経路
- 予算：low／medium／high／max

## 記憶

SQLiteが文書、事実、規則、session、message、監査eventの正本。監査eventはrequest単位のhash chainで結合する。

## K3から採ったもの

- 多軸選択
- 計算予算制御
- 状態継承
- 処理段階の明示

採らなかった物理構造：KDA tensor、Gated MLA、896 expert、学習済みAttention Residuals。MINIDORAでは明示状態、検索、規則、監査へ置換する。
