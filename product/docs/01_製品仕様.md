# MINIDORA製品仕様 1.0.0-rc.2

## 目的

登録済みの文書・事実・規則・session状態を根拠として、日本語中心の質問に対し、回答、保留、拒否のいずれかを監査可能に返す。

## 責任

1. 言語アドレス化
2. 文脈状態保持
3. 内容依存参照
4. 命令形・規則保持
5. 直列変換・合成
6. 候補形成
7. HDS採否
8. 日本語結果面
9. 永続化と監査

## 状態

- `PASS`：証拠があり、矛盾・危険が解消済み
- `SUSPEND`：未知、証拠不足、競合、矛盾
- `FAIL`：命令注入、安全・整合性境界違反
- `NOT_APPLICABLE`：宣言scope外

## 非機能

- 決定的処理
- SQLite WAL
- session／messages／監査のtransaction確定
- request size／rate limit
- API key／管理API fail-closed
- audit SHA-256 chain
- Windows／Linux／Docker
- test coverage 80%以上
