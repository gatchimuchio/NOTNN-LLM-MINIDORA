# 運用手順

## 本番設定

- `auth_required=true`
- user keyとadmin keyを分離
- TLS reverse proxy配下
- 原則loopback／内部network bind
- `data/`を永続volume化
- 定期backupとrestore訓練

## 診断

```bash
minidora doctor
pytest
python scripts/verify_product.py
```

## backup

```bash
minidora backup backups/minidora.sqlite3
```

SQLite online backup APIを使用する。

## 監査

```bash
minidora audit <監査ID>
```

`verification.status=PASS`、event数、head hashを確認する。

## ベンチ

```bash
python benchmarks/run_benchmark.py --output benchmark_results --repetitions 300
```

実K3との比較ではなく、K3構造射影版との局所比較であることを維持する。
