# K3差分とベンチ境界

## 動的比較の対象

実Kimi K3ではなく、K3公開構造から抽出した次の責任を同一局所課題へ投影した参照版。

- KDA相当の選択状態
- Attention Residuals相当のstage選択
- Sparse MoE相当のexpert routing
- effort別round予算

実K3のweight、2.8T規模、104B活性、multimodal、1M context、学習知識は実行していない。

## 構造差

```text
K3
= 学習済み汎用表現を時間・深さ・expert・予算で選択

MINIDORA
= 明示事実・規則・passageを選択し、HDSが出力権限を持つ
```

K3は汎用生成と多軸選択で優位。MINIDORAは根拠拘束、失敗状態、監査再現、低資源運用で優位。

## 現行局所結果

- 同一7課題：両者7/7
- 深度予算：両者low=SUSPEND、high=PASS
- 矛盾：両者SUSPEND
- 命令注入文書：MINIDORA=FAIL、K3射影版=SUSPEND
- 会話状態：両者PASS

速度差はMINIDORAが永続化・監査・HDSを含み、K3射影版がin-memory核だけであることを含む。
