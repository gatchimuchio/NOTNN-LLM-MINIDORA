# 02 原理の分別

## 観測 → パターン → 機構 → 局所原理候補

### A. 内容依存の選択参照・状態更新

KDAは時間方向、MLAは広域文脈、AttnResは深度方向に異なる実装を取るが、いずれも「現在入力・状態に応じて、必要な過去情報を選び、次状態へ反映する」責任へ写像できる。

KDA / MLA / AttnResという名前はLayer-0へ残さない。

### B. 条件付き変換

MoEは入力ごとに異なる変換器を選ぶ。post-trainingでもdomain・effortによる能力差が形成される。

Layer-0側へ残すのは「現在入力・状態に応じて、Pから適用する変換を選ぶ」責任であり、896 expertやTop-16ではない。

### C. 有効直列深度

93物理層、AttnRes、reasoning effort、agentic長期処理は、「中間状態を介して必要な回数だけ処理を継続する」能力と関連する。

Layer-0側では物理層数を捨て、状態を介した反復・多段変換として保持する。

## 別責任へ分離するもの

- training / post-training / RL: Pの形成過程
- visual projector: 入出力表現Adapter
- agent loop: 上位Runtime
- quantization / routing stabilization: 学習・実装効率
