# ソース実装

`src/minidora/` はMINIDORA実行系の現行実装を保持する。

## 言語規定

- 最上位理論正本: https://github.com/gatchimuchio/cognitive-engineering-foundations
- MINIDORA局所規定: `../設計/00_日本語基底規定_v1.md`
- 規定言語・基底言語・内部意味正本: 日本語
- 外国語: 実務上必要な外部互換境界のみ例外使用

外部API、外部規格、既存ファイル名・互換識別子等に英字が残る場合も、それを内部意味正本へ昇格させない。

## v0.5主要境界

| 実装 | 責任 |
|---|---|
| `規定参照.py` | 言語模型成立規定v7の版・commit・厳密言語模型/再現区分の現行参照 |
| `言語基底.py` | 日本語を唯一の規定・基底・意味正本とし、外国語互換を局所境界へ分離 |
| `言語確率法則.py` | 非ニューラル厳密言語模型核。厳密条件分布・系列確率・終端・模型状態保存 |
| `模型_v05.py` | v0.5統合窓口。厳密言語模型と能力模型を同時公開 |
| `模型.py` | v0.4由来の候補・関係評価。v0.5では能力模型核互換実装 |
| `runtime.py` | `言語模型核` / `能力模型核` / 計算実行器の統合。既存互換名として保持 |
| `hds入力参照境界.py` | HDS Compiler済Data→能力入力 |
| `hds_model_projection.py` | 能力結果→MINIDORA出力。既存互換ファイル名 |
| `hds判断主体.py` | MINIDORA能力出力の後段判断門 |
| `計算中間表現.py` | 計算専用中間表現 |
| `計算実行器.py` | 決定論的計算 |
| `layer0.py` | 旧API互換。現行言語模型核ではない |

英字の既存ファイル名は即時一括改名せず、互換性を壊さない形で段階移行する。新規の独自内部概念名は日本語を正本とする。
