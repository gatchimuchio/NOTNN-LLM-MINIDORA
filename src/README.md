## 能力状態差循環

```text
一次能力作用
↓
候補状態差
↓
差なし → 終了
差あり → 次作用選択
          ↓
         再作用
          ↓
         新状態差
```

重要境界:
- 同一証拠を段階名だけ変えて再加点しない。
- 状態差が無ければ再作用しない。
- HDS構文化器の後続利用に未確認追加条件が残る場合は発火させない。
- HDS固有型を能力核の内部正本にしない。
- 能力得点・作用差分を厳密言語模型確率へ混入しない。

局所正本: `../設計/30_MINIDORA能力状態差循環_v1.md`
