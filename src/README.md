## HDS-MINIDORA系実行正本 — HDS-first core

HDS-MINIDORAはMINIDORA30/80とは別系統の正本である。正本は `../HDS_MINIDORA_現行正本.md` を参照する。

2026-09-17以後、HDS-MINIDORA系の制御主語はHDSとする。

```text
HDS実行主体
→ 目的・状態・残差を保持
→ MINIDORA部品を作用として選択・起動
→ 作用結果を状態差として帰還
→ 再作用 / COMMIT / SUSPEND / FAIL
```

外向きのLLM成立契約、厳密言語模型核、MINIDORA30系 / MINIDORA80系の既存正本値はHDS-MINIDORA系によって置換しない。

局所正本: `../設計/60_MINIDORA_HDS自律接続_v3.md`（設計58・59の成立履歴を保持）

## v3の自動接続

不足文→観測要求、規則→説明仮説→識別予測→作業枝、原資料→範囲付き抽出圧縮、成功経験→純粋作用再現検証→条件付き再利用を通常循環で実行する。
未知例外は原因未確定の診断記録を保持し、安全契約のある場合だけ代替手段を構成する。作用列からは条件付き未来を構成し、途中の禁止状態も検査する。

`統合駆動_v2/` というパス名はv2利用コードとのimport互換のため保持している。内部版と保存形式はv3。HDS全体を固定手順へ還元する意味ではない。

## HDS-first 状態差循環

```text
HDS実行状態
↓
HDS作用機会
↓
次作用選択
↓
既存部品の作用
↓
HDS作用結果
↓
HDS状態差
↓
状態更新
↓
次作用 / COMMIT / SUSPEND / FAIL
```

重要境界:
- 作用を実行したことと、状態が変化したことを同一視しない。
- 同一作用・同一入力署名を反復しない。
- 実状態差が生じた場合だけ、同じ作用を新しい入力で再利用できる。
- 能力モジュールや模型核の局所成功を最終COMMITへ読み替えない。
- K3固有型を新HDS実行状態の正本へ入れない。
- HDS局所主体状態と永続人格を同一視しない。
- 能力得点・HDS状態差を厳密言語模型確率へ混入しない。

## 能力状態差循環

MINIDORA能力模型核内の候補状態差循環も維持する。

```text
一次能力作用
↓
候補状態差
↓
差なし → 終了
差あり → 次作用選択
          ↓
         再作用
          ↓
         新状態差
```

局所正本: `../設計/30_MINIDORA能力状態差循環_v1.md`

これはHDS-first全体状態差の下位作用であり、両者を同じ型へ潰さない。
