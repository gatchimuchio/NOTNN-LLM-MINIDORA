# MINIDORA 製品版 — 日常汎用能力受入 v1

目的はGPQA等の固定ベンチ攻略ではなく、模型核再学習なしの能力モジュール追加が日常タスク上の実効能力増加として成立することを確認すること。

受入対象:
- 基本会話
- ニュース外部参照
- 直前文脈の要約
- 明示文章の要約
- 直前応答の形式変換
- 情報抽出
- 決定論的計算
- 専用能力モジュール非該当時の既存MINIDORA 模型核委譲
- 各応答の実経路監査
- 応答間監査hash連鎖
- HTTP API経由の同一能力提供

禁止:
- benchmark問題番号やgold answerの埋込み
- 外部LLMによる回答代替
- 能力モジュール込み性能を模型核単体性能と表現
- 監査不能な自由生成を「完全追跡」と表現

性能目標は「GPT-4級の一般チャット使用感を目指す」。これは到達宣言ではなく開発目標であり、受入項目を増やして反復測定する。
