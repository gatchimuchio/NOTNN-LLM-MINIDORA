## 追記 — Windows標準入力の文字コード修正

初回PR CI run `34556070446`ではUbuntuの4構成とWindows / Python 3.14が成功し、Windows / Python 3.11〜3.13では継続会話の標準入力を既定のcp932で読んだため、UTF-8入力に対して`UnicodeDecodeError`が発生した。この初回失敗を成功として読み替えない。

追加CLIの標準入力・標準出力・標準エラーをUTF-8へ明示設定した。不正なUTF-8入力は追跡例外を露出させず、終了コード2で終了して後続を実行しない。既定文字コードを`PYTHONIOENCODING=cp1252`にした継続会話と、不正UTF-8の2件を追加した。
