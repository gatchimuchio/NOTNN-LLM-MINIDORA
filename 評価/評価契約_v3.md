# MINIDORA 評価契約 v3

## 目的

GPQA Diamondの現行MINIDORA中核正本性能を、LIVE参照を用いる全数E2E実測として固定する。
固定参照資料・保存済み検索結果・問題別再生束を現行性能測定へ再投入しない。

## 1. 現行正本評価境界

```text
GPQA Diamond 問題文 + 選択肢
↓
HDS構文化器Kernelで問題束を一度だけ形成
↓
実行時に新規取得する標準参照資料
↓
HDS駆動コア.選択実行
↓
中核内包の既存能力継承 / 再観測 / 再評価 / 非退行 / 学習循環
↓
COMMIT / SUSPEND
↓
実行後にgoldで採点
```

外付け能力モジュール、科学専門モジュール、旧HDS監督を現行中核正本値へ混入させない。

## 2. 正本運用条件

```text
外部評価 = GPQA Diamond
全問題数 = 198
選択 = 0..197 全数
GPQA CSV SHA256 = 41d1213cd7a4998605a26c2798500652572007161b3a92817ba46b35befcd305
選択肢シャッフル種 = 0
OpenAlex = 無効
Europe PMC = 有効
Crossref = 有効
Wikipedia = en
参照方式 = LIVE_ONLY
固定参照資料 = 禁止
中核入口 = HDS駆動コア.選択実行
既存能力継承 = 有効
学習循環 = 中核内包
外付け能力モジュール = 無効
科学専門モジュール = 無効
旧HDS監督 = 無効
gold利用 = 中核実行後の採点のみ
```

固定するのは評価構成であり、検索結果そのものではない。

## 3. HDS構文化器Kernel条件

現行正本測定では、各問題について問題束を一度だけ形成し、初期Rと中核実行が同じ束を再利用する。

- 問題束形成回数 = 1 / 問
- 全198問の形成総数 = 198
- 同一問題の原文を下流で意味決定のために再コンパイルしない
- 外部参照要求は形成済み問題束から降下する

## 4. 固定参照資料禁止

現行正本GPQAでは、固定参照コーパス、過去実行で保存した検索結果、問題別に凍結した参照資料束、再生用固定資料の外部知識入力利用、正解情報を利用して選別・整形した参照資料を禁止する。
公式問題集合の同一性確認用キャッシュは対象外とする。

## 5. 比較規則

- 現行正本値は、全198問を完走した同一runの最終中核出力から採用する。
- 同一run内で記録した初期継承状態から最終状態への差は、実行内状態遷移差として記録できる。
- 実行内状態遷移差を、外付け単一部品だけの因果効果へ読み替えない。
- 別runのE2E得点差は性能スナップショットの時系列差として扱う。
- 別run間のE2E得点差をコード変更だけの純粋因果差として扱わない。
- 同一workflow内で旧新を独立LIVE実行したpaired比較も、コードだけの純粋因果差とは扱わない。

## 8. 主張可能範囲

正本から直接主張できるのは、記録された評価条件における現行中核の実測性能、同一runで観測された状態遷移、問題束一問一形成、記録された候補被覆である。
他条件、他参照環境、他モジュール構成の性能を推定しない。
