# MINIDORA 評価契約 v3

## 目的

GPQA Diamondの現行MINIDORA中核を、**並列性能継承**と**直列学習効果**の二系統で測定する。
固定参照資料・保存済み検索結果・問題別再生束を現行性能測定へ再投入しない。

二系統の機械可読正本は `評価/GPQA評価二系統契約_v1.json` とする。

## 1. 現行正本評価境界

```text
GPQA Diamond 問題文 + 選択肢
↓
HDS構文化器Kernelで問題束を一度だけ形成
↓
実行時に新規取得する標準参照資料
↓
HDS駆動コア.選択実行
↓
COMMIT / SUSPEND
↓
実行後にgoldで採点
```

外付け能力モジュール、科学専門モジュール、旧HDS監督を現行中核正本値へ混入させない。


固定するのは評価構成であり、検索結果そのものではない。

## 3. 並列性能継承測定

並列測定は、現行MINIDORAが既存のGPQA性能を失っていないことを確認するための基準測定である。

```text
実行方式 = 問題独立並列
問題間状態継承 = 無効
全198問完走 = 必須
wall-clock上限 = 90分
性能継承下限 = 43 / 198
```

各問題は他問題の記憶・認識・形成関係・作用適応記憶・実観測参照を受け取らない独立状態から開始する。
並列化の粒度は実装上変更してよいが、問題間状態継承を生じさせてはならない。

判定は次とする。

- `並列正答 >= 43` : 少なくとも既存40/198の性能継承を確認する。
- `並列正答 < 43` : 性能退行と扱う。
- 43/198は2026-10-02に確認した並列性能継承runの再現下限である。2026-09-27の40/198正本値は履歴スナップショットとして保持する。
- 未完走または90分超過は並列正本値として採用しない。

## 4. 直列学習効果測定

直列測定は、同一Coreを198問で継続使用し、問題間状態継承がE2E性能へ与える効果を観測するための測定である。

```text
実行方式 = 同一Core直列
問題順 = 0..197
問題間状態継承 = 有効
全198問完走 = 必須
wall-clock上限 = 90分
採点結果の学習利用 = 禁止
```

継続対象は、HDS記憶、根拠有効な確定認識、形成関係、作用適応記憶、実観測参照とする。
正解ラベルおよび採点結果を次問へ学習入力として与えてはならない。

90分以内に198問を完走しないrunは、直列学習効果の正本値として採用しない。

## 5. 二系統比較

並列と直列は**同一リポジトリ版**で測定する。
問題集合、選択肢順、参照条件、中核入口、gold境界等の共通条件を一致させ、意図的な差は原則として**問題間状態継承の有無と、それに伴う実行方式**に限定する。

```text
学習効果差分 = 直列正答 - 並列正答
```

解釈は次とする。

- `並列 >= 43` かつ `直列 > 並列` : 性能継承に加えて、GPQA上で正の学習効果を観測。
- `並列 >= 43` かつ `直列 = 並列` : 性能継承を確認。GPQA上の学習効果は未観測。
- `並列 >= 43` かつ `直列 < 並列` : 性能継承は並列側で確認できるが、問題間状態継承による性能毀損を観測。
- `並列 < 43` : 性能継承不成立。直列値が高くても並列性能退行を打ち消したとは扱わない。

直列と並列の差を、学習機構だけの純粋因果差とは断定しない。LIVE参照の揺らぎ等を含む観測値として記録する。

## 6. HDS構文化器Kernel条件

各問題について問題束を一度だけ形成し、初期Rと中核実行が同じ束を再利用する。

- 問題束形成回数 = 1 / 問
- 全198問の形成総数 = 198
- 同一問題の原文を下流で意味決定のために再コンパイルしない
- 外部参照要求は形成済み問題束から降下する

## 7. 固定参照資料禁止

現行正本GPQAでは、固定参照コーパス、過去実行で保存した検索結果、問題別に凍結した参照資料束、再生用固定資料の外部知識入力利用、正解情報を利用して選別・整形した参照資料を禁止する。
公式問題集合の同一性確認用キャッシュは対象外とする。

## 8. 時間条件

`timeout-minutes: 240` は過去workflowの実行停止用マジックナンバーであり、GPQA性能評価条件としての根拠を持たない。
今後の並列性能継承測定と直列学習効果測定は、ともに**90分をhard wall-clock上限**とする。

時間上限は得点へ加点・減点する指標ではなく、全数測定を正本値として採用できるかの受入境界である。

## 9. 現行性能継承下限

2026-09-27採用の40/198正本値は履歴スナップショットとして保持する。能力継承の再現下限は、2026-10-02の問題独立並列198問完走runで確認した43/198とする。

```text
現行MINIDORA中核
GPQA-E2E-LIVE
40 / 198
20.2020202020202%
回答 144 / 198
SUSPEND 54
FAIL 0
```

40/198の正本値と43/198の能力継承再現下限を混同しない。現行revisionは並列198問全数を再測定し、43/198以上を確認して初めて能力継承の再現成立とする。

## 10. 比較規則

- 正本値は全198問を完走した同一runの最終出力から採用する。
- 未完走の部分値を正本値へ採用しない。
- 別runのE2E得点差は性能スナップショットの時系列差として扱う。
- 別run間のE2E得点差をコード変更だけの純粋因果差として扱わない。
- 同一workflow内で独立LIVE実行したpaired比較も、コードだけの純粋因果差とは扱わない。

## 11. 履歴系列

2026-09-24の39/198正本、2026-09-23の29/198正本、MINIDORA30、MINIDORA80はGit履歴と `開発正本履歴.md` から復元する過去セーブポイントであり、現行値ではない。

## 12. 主張可能範囲

正本から直接主張できるのは、記録された評価条件における実測性能、並列側で確認した性能継承、直列と並列の差として観測した学習効果、問題束一問一形成、記録された候補被覆である。
他条件、他参照環境、他モジュール構成の性能を推定しない。
