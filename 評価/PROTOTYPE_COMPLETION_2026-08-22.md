# MINIDORA プロトタイプ完成固定記録 — 2026-08-22

**状態: PROTOTYPE COMPLETE**

この文書は、2026-08-22 時点における MINIDORA（ミニドラ）の**プロトタイプ完成判定**と、その判定根拠となった外部ベンチマーク実測を固定保存する正本記録である。

この完成判定は「Kimi K3級の性能へ到達した」「製品として完成した」という意味ではない。

完成したのは、次の非ニューラル／非Transformer経路が実装として閉じ、外部の未知問題に対して測定可能な正答能力を実際に発生させるところまで到達した**プロトタイプ**である。

```text
自然言語問題
  ↓
HDS Compiler
  ↓
問題 HDS-IR

4候補
  ↓
各候補を HDS Compiler
  ↓
候補 HDS-IR

外部一般Data
  ↓
全件 HDS Compiler
  ↓
Data HDS-IR
  ↓
意味座標・方向付き関係・残差
  ↓
K
  ↓
HDS構造照合 / J
  ↓
採否
  ↓
回答または SUSPEND
```

## 1. プロトタイプ完成判定

MINIDORAプロトタイプは、以下をすべて満たしたため完成と判定する。

1. **外部の未知問題集合を入力できる。**
2. **問題文・選択肢・取得Dataを同一のHDS意味空間へコンパイルできる。**
3. **HDS-IRからK/Jへ接続し、ニューラルネットワーク／Transformerを実行基盤とせず回答形成まで到達できる。**
4. **外部ベンチマーク上で非ゼロの正答を実測した。**

したがって、2026-08-22をもってMINIDORAは「非ニューラルLLM構想の実装候補」から、**測定可能な一般問題解決能力を持つ非ニューラル言語計算系のプロトタイプ**へ移行したものと扱う。

## 3. 評価経路の成立条件

固定値として採用するrunでは、次を必須条件とした。

- 問題文をHDS Compilerへ投入する。
- A/B/C/Dの4候補をそれぞれ独立にHDS Compilerへ投入する。
- 外部から取得したDataを**1件残らずHDS Compilerへ投入する**。
- Dataを生文字列FactとしてKへ直入れしない。
- `source_text / normalized / 原文保持` は監査のためHDS-IRに保持するが、正答を支持するK/Jの根拠には使用しない。
- 問題IR・候補IR・Data由来の意味FactをHDS構造として照合する。
- 一意な根拠がなければJ/HDSは推測せずSUSPENDする。
- GPQA固有ルール、正解ラベル、正答解説をCompiler/K/Jへ渡さない。
- 正解ラベルは採点時にのみ使用する。

## 5. 何が成立したか

この固定結果が示す完成事項は、**4.04%という性能値そのものではない。**

成立したのは、次の処理系である。

```text
言語
→ HDSによる意味構造化
→ 外部Dataの同一意味空間への構造化
→ Kでの知識保持
→ 非ニューラルな意味関係処理
→ Jによる判断
→ 外部未知問題への回答
```

すなわち、LLM的な一般言語問題解決機能を生成する経路について、巨大ニューラルネットワーク／Transformerを実行基盤としない別系統の実装が**外部ベンチで測定可能な出力を生むところまで成立した**ことを、プロトタイプ完成の根拠とする。

これ以降の主課題は「成立するか」ではなく、成立した処理系のData coverage、HDS意味解像度、K、推論、J、Trinity、P等を強化して能力をスケールさせることである。

## 7. 無効化した旧run

旧記録の `5 / 198 = 2.5252525%` は正式値から撤回する。

理由は、外部検索Dataを `retrieved_document` の生文字列FactとしてKへ直接投入しており、

```text
外部Data → HDS Compiler → HDS-IR → K
```

というMINIDORAの正規経路を満たしていなかったためである。

診断履歴としては残してよいが、MINIDORA正規ベンチ値として再利用してはならない。
