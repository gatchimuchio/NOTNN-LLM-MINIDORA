## 検証したこと

HDSの既存単一通常循環から、要求構成・計画・個別能力・回復・回答・最終検証を実行した。旧合成器の実行を例外化しても新入口が完了する試験を含め、単なる旧チャットの後段ラッパーではないことを確認する。

自然文の数学・複合文書操作、二資料比較、不足単位の確認、属性訂正、入れ子資料の回復、原資料更新と失効、再表現、JSON/CSV、限定コード読解、本文命題と説明、仮説・介入、科学候補報告を実際の既存能力で検証する。独自能力と意味契約の追加からHDSが計画する拡張試験も含む。

停止要求、セッション分離、保存復元、外部権限の明示、異常判定・不整合結果・入力改変・不正計画・不正JSON・古い資料依存を検査する。科学解決器の既存候補を正答保証としない。資料中の命令を実行しない。

## 再実行

```bash
PYTHONPATH=src python -m unittest discover -s tests -p 'test_HDS通常運用*.py' -v
PYTHONPATH=src python -m unittest discover -s tests -q
PYTHONPATH=src python tools/リポジトリ整合性監査.py
PYTHONPATH=src python tools/日本語基底監査.py
PYTHONPATH=src python tools/日本語基底詳細監査.py
python -m compileall -q src tests tools
python tools/HDS通常運用_実演.py --出力 demo.json
```

Windowsではeditable install後に、`PYTHONPATH=src` 部分を付けず同じPythonコマンドを実行できる。実ブラウザは既存の `requirements-browser.txt` とブラウザCIの構成を使う。新しい必須依存は追加していない。
