# MINIDORA 開発再開記録

日付: 2026-09-09

## 状態

2026-09-08のCore37正本固定後に設定した開発凍結を、ユーザー明示指示により解除する。

Core37の実測値は比較基準として保持し、過去の開発終了記録を履歴から削除・上書きしない。

## 再開理由

新観測により、HDSの意思決定プロセスが一つの意思決定として連続するためには、判断主体の現在解釈が局所的に保持され、後続判断の起点として実際に利用され、結果によって更新される必要があることを再監査対象とした。

MINIDORAへは永続主体としてではなく、LLM Runtime寿命に限定した局所作業状態として射影する。

## 今回の実装境界

- 同一Runtime内に `局所解釈キャッシュ` を置く。
- 各turn開始時に更新前状態を `局所解釈起点` として固定する。
- HDS有無にかかわらずturn完了後に局所状態を更新する。
- 保留・失敗で採用済み焦点を無言上書きしない。
- Runtime間で状態を共有しない。
- 永続化、端末間同期、長期目標維持は実装しない。
- Agent / AGIの長期主体責任をLLMへ混入しない。

局所設計正本: `設計/36_MINIDORA_局所解釈起点_v1.md`
