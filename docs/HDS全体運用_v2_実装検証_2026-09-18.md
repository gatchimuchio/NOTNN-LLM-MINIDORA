## 実装した機能

| 項目 | v2の実装 | 保持する境界 |
|---|---|---|
| 知識形成 | 提供原文から命題・規則を、出典位置・版・未解釈を持つ資産へ形成。複数資産を前提に支持・反証を導出する。 | 既存の有限構文と推論。登録を現実の事実認定へ昇格しない。 |
| 知識更新 | 変更した原資料と形成資産を同じ採用境界で更新し、依存成果を失効。全知識への照会は集合への資料追加でも再評価する。 | 知識量や出典の信頼性を自動保証しない。 |
| 手順形成 | 成功した純粋工程を同じHDS内でキャッシュなしに再実行。一致した場合だけ計画・条件・入力束縛を保存。 | 外部作用・未契約の追加能力・回復枝は再現しない。 |
| 手順利用 | 現行目的から作った計画と照合して使い、変更された資料の値で計算し直す。保存復元後も利用。 | 回答値の保存再生ではない。現在の計画器を省略した高速化や、未知アルゴリズムの発明ではない。 |
| 原記録同期 | 原資料、旧版、原要求、成功成果、依存を既存長文脈庫へ自動同期。版変更時に下流を失効。 | 語一致・必須IDによる選択。任意の意味検索・巨大文脈の意味理解ではない。 |
| 原文再参照 | 同じ会話から原文を取り出し、実際に読んだ参照を成果依存へ返す。 | 必須原文が容量を超えたら切断せず保留する。 |
| 製品・保存 | `--知識` ファイル投入、同じHDS製品への接続、形成再実行の無効化、v2状態保存・復元。 | v1保存物は無言移行せず拒否。旧データは削除しない。 |

## 具体的に検証した利用

人工資料の13段階の連続実演がすべてCOMMITした。

1. 別資料の「太郎は猫」と「すべての猫は哺乳類」から結論を導出し、実導出を説明する。
2. 反対記載を知識へ追加すると以前の全知識回答を無効化し、再計算で支持・反証の両方を反映する。
3. 保存復元後も原文を再参照する。
4. 二資料の比較で6工程を実再現し、一致した手順を形成する。
5. Aの売上を75→90へ変更すると、形成手順を利用しても現在値から再計算し、差を−15→−30へ変更する。この比較実演では結果キャッシュを無効化した。
6. 保存復元後の再計算でも手順を利用し、旧回答の値を転記しない。

単体・接続試験では、保存ASTの再ハッシュ改変、保存手順の型改変・外部権限化、追加知識による旧結論の失効、入力取消、原記録保存失敗、予算不足、必須原文の切断拒否、セッション分離、再現不一致、未契約能力の再実行拒否を確認した。
