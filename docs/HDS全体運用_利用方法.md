# HDS-MINIDORA 全体運用 v1 の利用

既存モジュールをHDSが工程ごとに起動する追加入口。旧製品の既定挙動は変更しない。
仕様は `設計/63_HDS_MINIDORA_全体運用_v1.md`。

## 起動

リポジトリのルートで実行する。

```bash
python -m pip install -e .
python -m minidora.製品版 --HDS --serve
```

ブラウザは `http://127.0.0.1:8080/`。PORT環境変数を指定した場合はそのポートを使う。外部公開・認証サービスではない。

会話CLI:

```bash
python -m minidora.HDS運用
```

## 同じ案件での比較・訂正・更新

```text
資料「A」を登録:{"売上":75,"費用":50,"単位":"円"}
資料「B」を登録:{"売上":60,"費用":40,"単位":"円"}
この2つの売上を比較して
訂正:属性は費用です
詳しく説明して
資料「A」を更新:{"売上":75,"費用":70,"単位":"円"}
再計算して
```

売上差は右－左で-15円、訂正後の費用差は-10円、更新後は-30円となる。資料の記載値の比較であり、資料の真偽や原因を認定しない。

## 提供知識から根拠説明

```text
知識「基礎」を登録:太郎は猫です。すべての猫は哺乳類です。
資料「基礎」から「太郎は哺乳類である」の根拠を説明して
短く説明して
```

対応した命題・規則から説明する。任意の記事・未知語義の理解を完成したものではない。

## 文書・計算・集合

```text
2+3
「x**2+3*x」をxで微分して
資料「文」を登録:売上は711です。費用は32です。
資料「文」を要約して、その結果から数字を抽出して
```

最大8資料の数量集合では合計・平均・件数・最大・最小等と表現変更に対応する。二資料比較と数量集合は表現契約が異なり、二資料比較後の「それを表にして」は現行部品では未対応。

## 保存と復元

```bash
python -m minidora.HDS運用 --保存 会話.json "2+3"
python -m minidora.HDS運用 --復元 会話.json --保存 会話.json "詳しく説明して"
python -m minidora.HDS運用 --資料 A=a.json --資料 B=b.json "この2つの売上を比較して"
```

`--json`を付けると、終端、本文、能力結果、HDS作用履歴をJSONで返す。

## 外部取得

既定では禁止。既存SearXNGと公開本文取得器を用いる。ローカルSearXNGは既存の `deploy/searxng/` の手順に従って用意する。

```bash
python -m minidora.HDS運用 --外部読取 "機器Aの電圧をVで調べて"
```

上記の機器Aは入力形式の説明用であり、実在資料が取得できる保証はない。取得失敗を固定した答えで補わない。サンドボックスの試験では、ネットワーク供給だけ人工資料に差し替え、実際の取得・計画・再取得・回答部品を検証する。公開WebのLIVE性能は未測定。

## Pythonからの利用

```python
from minidora.HDS運用 import HDS運用セッション

会話 = HDS運用セッション("仕事")
会話.資料を登録("A", '{"売上":75,"単位":"円"}')
会話.資料を登録("B", '{"売上":60,"単位":"円"}')
結果 = 会話.応答("この2つの売上を比較して")
print(結果.状態, 結果.本文)
```

型付き目的は `目的を実行(汎用要求IR)`、役割付き目的は `役割目的を実行(意味目的, 原文=...)`、明示合成は `合成を実行(原文, 合成計画, 資料)`。いずれも同じHDS循環で実行する。追加能力・追加役割作用は構築時に信頼する実装を渡す。

コードの生成→評価の動く例、外部取得、追加能力登録、取消、保存復元は `tests/test_HDS全体運用_*.py` を参照する。

## 実演と試験

```bash
python tools/HDS全体運用_実演.py --output 実演.json
python -m unittest discover -s tests -p "test_HDS全体運用_*.py" -v
python -m unittest discover -s tests -q
```

この版の対象は通常運用の接続単位。一般自由作文、未知アルゴリズム生成、任意自然言語、長文脈の完全自動同期、経験からの新能力自動形成まで完成したとは扱わない。
