## 1. 今回の実装

HDSを唯一の実行主体とし、依頼構文化・目的計画・既存能力の各工程・結果の帰還・局所回復・最終採否を同じ通常循環へ接続した。既存の合成器へ依頼全体を渡し、後からHDSで承認するラッパーではない。

既存のHDS実行主体へ、状態を読んで作用候補を供給する `HDS作用供給器` と協調停止を追加した。生成された工程も、通常のHDS作用選択・状態差・再作用抑止・依存・予算・最終検証を通る。新引数を使わない旧経路は維持する。

48個の既存能力・接続能力を共通目録に登録した。基礎29、会話7、数量集合1、命題2、文脈命題2、改善6、科学接続1である。科学接続1は多数の既存科学解決器を呼ぶ橋であり、専門解決器数を48に混同しない。登録数そのものを一般能力の完成数とは扱わない。

現在の公開構文化器を使い、全IRを保存したまま局所能力用の意味ビューと監査責任を分離した。既知の構文化器生成メタデータだけを厳密な条件で分離し、実際の意味関係・否定・残差・未知の監査種別は免除しない。分離した未観測項目を解消済みとは認定しない。

## 2. 実際に接続・実行した利用

| 利用 | 実行内容と範囲 |
|---|---|
| 数式 | 通常の算術依頼、多項式の微分、型付き数学目的をHDSの工程として実行。 |
| 文書合成 | 一つの依頼内で要約→数値抽出を実行し、中間成果を後続工程へ渡す。 |
| 比較・集合 | 二資料の比較、三資料の合計・平均、数量集合の表現変更。単位と条件を保持。 |
| 確認・訂正 | 単位不足への返答から同じ目的を再開し、属性の訂正で計算・回答を更新。 |
| 資料更新 | 依存する採用成果を失効し、最新の資料で再計算。無関係な資料では焦点を失効しない。 |
| 説明の変更 | 採用済み成果から再表現し、計算・外部取得を不要に再実行しない。 |
| 知識資料 | 提供した知識を原資料として保持し、対応した命題規則から根拠を説明。未知片は残す。 |
| 失敗・回復 | 入れ子資料の代替読取、取得不足後の焦点化した再取得。既存の有限回復契約に限定。 |
| コード | 型付きのコード仕様から既存生成→評価へ同じHDS循環で接続。自由文から未知のアルゴリズムを作ったとは扱わない。 |
| 科学 | 科学問題資料を既存解決器へ渡し、選択内容・計算値・限界を成果に保持。新GPQA評価ではない。 |
| 追加能力 | 信頼する追加実装と意味契約を渡し、運用本体を編集せず登録・実行。 |
| 保存・復元 | 原資料、版、依存、前回目的、焦点、履歴を保存し、復元後の説明・再計算へ利用。 |
| 製品 | 同じAPI・UI・監査台帳にHDS専用入口を追加。旧既定入口を変更しない。 |

外部取得試験はネットワーク供給を人工資料に差し替えた。既存の実際の計画・取得本文処理・回復・回答を通すが、公開WebのLIVE性能を測ったものではない。

## 6. 安全性・信頼性への影響

状態変更の採用はHDSのCOMMIT後。途中成果の成功で案件全体を成功にしない。権限は環境と個別要求の両方で要求し、保存物から昇格しない。任意Pythonを資料から実行・復元しない。

純粋な既存部品だけを同一の完全入力・版・目録で再利用する。追加能力、外部取得、可変文脈、探索全体を既定でキャッシュしない。

取消・期限は作用間での協調停止であり、実行中の任意関数を強制終了するものではない。SHA256は整合性検査であって認証・真正性・改ざん不能化ではない。サーバはlocalhost限定であり、インターネット公開向けの認証サービスではない。

## 7. 残件と今回の完成境界

今回完成した単位は、HDSが既存能力の工程を運用し、同じ依頼・資料・成果の下で会話を継続する追加経路である。前回提案した全開発範囲の一括完成ではない。

自然文の理解範囲は既存の局所文法を継承する。48登録を、任意の依頼から全48能力を自動利用できるという主張にしない。一般自由作文、任意記事の読解、未知アルゴリズム構成、広域知識の獲得・形成は残る。

経験は成功履歴の保存であり、新しい能力を一般化・生成する学習ではない。動的作用の再実行契約が未完成のため、この入口の自動経験形成は無効。既存v3の形成機構は保存する。旧長文脈庫への資料自動同期も残る。

能力の実出力と元要求・依存の整合は検査するが、それだけで現実世界の主張を真と認定しない。各専門モジュールの能力範囲・限界を継承する。
