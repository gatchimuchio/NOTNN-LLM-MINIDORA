# MINIDORA 製品版アーキテクチャ v1

```text
User / Web UI
    ↓
Product Chat
    ↓ Capability Router
    ├─ Basic Chat
    ├─ News Retrieval
    ├─ Summarization
    ├─ Context Transform
    ├─ Information Extraction
    ├─ Deterministic Calculation
    └─ Existing MINIDORA Core
    ↓
Response Composition
    ↓
Governance Ledger (input / route / module I/O / references / state / final)
```

Coreは再学習しない。能力不足は原則Moduleとして追加する。Module不成立時は勝手な回答を作らず、次の適切な経路へ透過または保留する。
