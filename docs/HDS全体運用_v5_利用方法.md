# HDS全体運用v5：関係・条件から根拠を説明する

2026-09-18 / 実装契約：[設計67](../設計/67_HDS_MINIDORA_関係読解と根拠説明_v5.md)

## 登録した文章に質問する

```python
from minidora.HDS運用 import HDS運用セッション

会話 = HDS運用セッション("関係の説明")
登録 = 会話.資料を登録(
    "手順",
    "装置Aは有効である。もし装置Aが有効なら、稼働する。",
)
if not 登録.成立:
    raise RuntimeError(登録.本文)

回答 = 会話.応答("資料「手順」をもとに、装置Aが稼働するかどうか説明して")
print(回答.状態)
print(回答.本文)
```

この例では、元の二つの記載と「条件適用」を示して、資料内の支持を説明する。条件の記載だけで有効という事実がなければ、稼働を断定せず未確定と確認候補を返す。

同じ資料について、次も使える。

```text
資料「手順」から「装置Aは稼働する」の根拠と条件を説明して
資料「手順」ではなぜ装置Aは稼働するのか説明して
登録資料から装置Aは稼働するかどうか確認して
資料「手順」をもとに、装置Aは稼働するかどうか説明して、文章にして
```

「なぜ」の内容を自動的に事実としない。否定の根拠しかなければ反証、両方あれば矛盾、導けなければ未確定を表示する。条件の適用は、現実の因果関係を検証したことではない。

v4の要約・観点比較・確認事項提案、数量v3、既存の専門能力は従来の構文で利用できる。この経路へ全ての依頼を無理に変換する必要はない。

## 明示的な不足調査

```python
from minidora.HDS運用 import HDS運用セッション

会話 = HDS運用セッション("許可した公開調査", 外部読取許可=True)
会話.資料を登録("手順", "もし装置Aが有効なら、稼働する。")
回答 = 会話.応答(
    "資料「手順」をもとに、装置Aが稼働するかどうか説明して、不足は公開資料で調べて",
    外部読取許可=True,
)
print(回答.本文)
```

実際の公開調査には、既存の検索供給器・公開HTTPS取得器が利用できる環境が必要。上の装置名は使い方を示す仮の名称であり、現実に検索可能な資料が存在すると保証する例ではない。

セッションと今回の呼出の両方で許可しなければ通信しない。送るのは指定した問いと対象語等であり、原資料本文は送らない。ただし問いに機密が含まれる場合は、公開調査を許可する前に除くこと。

取得成功後も本文を関係読解し直す。検索語があるだけでは結論を得たと扱わない。公開資料とローカル資料の同名対象を自動同一化しない。取得失敗や未確定を含む場合、説明のCOMMITは「問いが支持された」意味ではない。

## 表示変更・更新・再計算

```python
print(会話.応答("文章にして").本文)
print(会話.応答("引用形式にして").本文)
会話.資料を登録("手順", "装置Aは稼働しません。", 更新=True)
回答 = 会話.応答("再計算して", 外部読取許可=True)
print(回答.本文)
```

資料更新後は旧回答が失効し、旧回答の単なる再表現は拒否する。以前の目的に公開調査が含まれる場合、再計算時も今回の外部許可が必要。公開回答の再表現は保存した本文を使い、最新情報を再取得しない。

## 保存・旧版からの移行

```python
from pathlib import Path
from minidora.HDS運用 import HDS運用セッション, 旧保存を移行

# 元ファイルを上書きしない。
原本 = Path("旧v4.json").read_text(encoding="utf-8")
新会話 = 旧保存を移行(原本)  # 旧保存が外部許可付きなら呼出側設定も一致させる。
with Path("新v5.json").open("x", encoding="utf-8") as 保存先:
    保存先.write(新会話.保存())
復元 = HDS運用セッション.復元(新会話.保存())
```

CLIでは次のとおり。通常復元はv5のみ、明示移行は標準v1〜v4に対応する。既存出力先・同一ファイルへの移行は拒否する。

```bash
python -m minidora.HDS運用 --移行元 旧v4.json --保存 新v5.json --json
python -m minidora.製品版 --HDS --serve
```

旧原本と履歴・依存は保持するが、旧成果と旧形成手順は再採用しない。過去の移行履歴も旧原本内に残る。未知の独自能力目録の移行は未対応。

## 対応範囲

この増分は名詞述語、サ変の一部活用、明示条件、同一文の限定的な省略、一意な近距離照応、既存命題文法を対象とする。未知の例外は資料全体の推論採用を保留する場合がある。任意文章の理解、自由作文、翻訳、広域知識、未知課題の一般解法まで完成したものではない。
