# MINIDORA ブラウザ取得・操作 v0.1

日付: 2026-09-11
基点commit: `31f3c1733c876cf2929389dc71b12319b6ca0888`
対象: 開発一覧⑮の実ブラウザ描画・限定表示操作・明示リンク移動。

## 1. 作用

```text
明示した開始URL・許可資源URL・工程
→ 公開HTTPS資源を検査して取得
→ オフライン設定の新規Chromiumコンテキストへ応答を供給
→ JavaScript描画の状態を観測
→ 指定IDと期待表示を検査して表示ボタンを操作／リンク先へ移動
→ 描画後の指定本文・表を取得
→ 既存JSON処理・数値抽出・実HDSへの素材
```

第4バッチの静的本文取得器は置換しない。新しいブラウザ機構を任意依存として追加する。取得したHTMLのソースと、JavaScriptが生成したDOM、描画されたテキストは異なる対象として扱う。

Core、HDS Compiler、既存Module、GPQA正本、標準チャット入口、GUI-Shellは変更しない。PlaywrightとChromiumは本機能にだけ必要。本体の必須依存は変更しない。

## 3. 通信と作用の境界

開始URLと資源URLを、同じ生成元の正規化済みHTTPS URLとして完全列挙する。ワイルドカード・動的な許可拡大・未知クエリを許可しない。認証情報・私設IP・非標準ポート・URL断片は拒否する。許可URLは読み取りに使ってよいエンドポイントであることを呼出側が判断する。GETであること自体はサーバ側無副作用の証明ではない。

Chromiumコンテキストをオフラインにし、全要求をルーティングする。ブラウザの要求を`continue`や`route.fetch`へ流さず、既存`公開本文取得器._一回取得`で公開IPへの固定接続とTLS検証を行い、その応答だけを`fulfill`する。ブラウザのCookie・Authorization・要求本文・RefererをPython取得器へ継承しない。認証済みプロファイルやログイン状態を持たない。

GET以外、未許可URL、子フレーム、自動ページ移動、WebSocket、別窓、ダウンロードは未対応。検出した拒否は要求全体を不成立にし、直前までの値を最終成果にしない。HTTP転送、圧縮応答、UTF-8以外も本版は拒否する。以前の静的取得器が対応する転送を、本ブラウザ入口がすべて継承したとは呼ばない。

HTML・JavaScript・CSS・JSON・text/plainの対応する要求種別だけを供給する。元応答のCSPがある場合は保持し、さらにフレーム・フォーム送信・worker・object等を禁止するCSPを併用する。画像・フォント等も完全なサイト再現の対象ではない。オフライン状態や追加CSPのため、通常ブラウザとは異なる表示・挙動になるサイトがある。

この処理はブラウザの脆弱性、任意JavaScript、OS全体を隔離するセキュリティ製品ではない。信頼できないサイトは別のOS・コンテナ等の境界で運用する必要がある。同期JavaScriptが停止しない場合などのプロセス強制終了・厳密なCPU/メモリ・総時間制限は本APIにはない。通常のページ待機上限だけで全実行時間を保証しない。

## 4. 工程と観測

要求は開始URL、許可URL、工程列、待機上限。実値はDataで渡す。工程は`表示待機 / 表示操作 / リンク移動 / 本文取得 / 表取得`。対象は明示したDOM ID、操作時には期待する表示文字列も必須。自由文から適切な要素を発見する機構は追加しない。

観測はDOMシリアライズ、表示本文、可視のID付き要素、リンク、ボタン、表の構造を保持する。CSS表示条件による可視判定であり、画面の全画素の理解・アクセシビリティ木の完全な意味理解ではない。iframe・図・Shadow DOM・IDのない要素等は未対応範囲がある。

表示操作は、フォーム外・有効・`type=button`の対象に限定する。観測したDOMと現行DOMが一致するかを、同じJavaScriptタスク内で確認してからDOMの`click()`を呼ぶ。これは実ブラウザ上のイベント処理だが、物理ポインタ入力や`isTrusted=true`の操作ではない。ボタンの意味が本当に表示だけかは上位の指定責任であり、付随通信は別途検査する。

リンク移動は観測した通常リンクのhrefを検査し、明示許可された移動先を`goto`で開く。アンカー自身のonclickは実行せず、別窓・download属性を拒否する。移動前後のURLと観測を記録する。リンク検査から遷移までの全Web環境の原子的同一性を保証するものではない。

非同期描画は`表示待機`でID・必要なら表示文字列の一致を待つ。待機成立をページ全体の安定や意味的十分性とは呼ばない。取得後に観測差があれば旧結果を採用しない。

## 5. 表・本文と後続利用

本文取得は指定した可視要素の`innerText`。原HTMLバイト列の無改変引用ではない。表取得は行列・見出しセル・結合情報を保持したうえで、非空・矩形・結合セルなしの場合だけJSONの二次元配列を返す。セルは文字列のまま保持し、番号001を数値1にしない。結合セル、不揃いな表、隠れた行・セル、入れ子表は補完・平坦化せず保留する。

表のJSONは第13バッチの読取・位置選択・値取出へそのまま接続する。動的に得た値が後段へ渡ることで能力接続を確認する。どの表・欄を選ぶべきか、近接する留保を同伴すべきかの意味判断は上位に残す。

結果には最終観測、取得対象、前後観測のhash、資源取得・拒否記録、取得時刻、ブラウザ版、供給区分を含む。出典の公開時刻は未確認のままにする。試験供給器を使った結果は明示的に「試験供給」とし、公開サイトLIVE取得へ読み替えない。固定試験資源をGPQA正本へ接続しない。

`ブラウザ記録整合`は記録hashと選択要素・表からの抽出一致を検査する。再訪問、JavaScript再実行、原HTMLからの独立再現ではなく、署名・認証でもない。全記録とhashを作り直す改変を検出する保証はない。

## 6. 実行の寿命・上限

一要求でブラウザを新規起動し、成功・失敗の双方でcloseする。コンテキストを次の要求へ共有しない。Playwrightが使う一時プロファイルやブラウザバイナリのディスク利用は存在するため、プロセス全体を「ファイルI/Oなし」とは呼ばない。

許可URL64件、資源要求64回、単一資源1 MB、累積受信4 MB、工程16件、通常待機100〜10000ミリ秒。DOM500000文字・5000要素、可視ID付き要素256件、要素本文100000文字、表128行・32列、観測1 MB、最終記録2 MBを上限とする。上限時は切断して成功しない。

停止要求は工程・待機反復・取得境界で確認する。実行中のOS DNS待ちやJavaScriptへ強制割込みするものではない。既存合成器から内側への停止コールバック伝播は未実装で、Module経由は外側の呼出前後の検査になる。

## 7. 導入・試験

```bash
python -m pip install -r requirements-browser.txt
python -m playwright install chromium
python tools/ブラウザ閲覧デモ.py --描画試験 --値 731
python tools/ブラウザ閲覧デモ.py --要求 閲覧要求.json --外部読取許可
```

公開閲覧要求の構造例（URL・対象IDは実対象に合わせて呼出側が指定する）:

```json
{"開始URL":"https://example.com/catalog","許可URL":["https://example.com/catalog"],"工程":[{"操作":"表示待機","対象ID":"data","期待表示":null},{"操作":"表取得","対象ID":"data","期待表示":null}],"待機ミリ秒":3000}
```

通常CIではPlaywrightを必須にせず、実ブラウザ試験はskipと明示する。別のブラウザCIでは導入・描画・URL移動・合成・実HDS接続を必須実行し、依存不足をskipへ変えない。サンドボックスの管理ポリシーによるURL移動禁止は変更せず、局所DOM描画とCIの移動試験を分ける。

未完了: 任意サイトへの完全対応、ログイン・入力・フォーム送信・購入・ダウンロード、一般的な画像やPDF理解、自由文での要素選定、標準チャットへの自動接続。⑮全体・GPT-4同等性の完成認定ではない。
