# K構造優先射影 v0.16 候補

> この文書はv0.15受入後の次段候補。v0.15の採否には含めない。

## 原則

Kへ渡す情報は「多いほど良い」ではない。

Compilerが安全な構造を作れた場合、その構造と同じ内容を表層語bagとして二重に渡すと、Kのdocument-level再結合で無関係語が再混入する。

したがってData/候補のK射影は次の優先順位とする。

```text
安全な関係構造あり
  → 関係 + その端点からなる連結意味核
  → 無関係な主題語bagは渡さない

安全な関係構造なし
  → 対象/実体/属性/値/通常状態等の語意味へ縮退
```

## 目的

- 構造Factと語bagの二重加点を避ける
- 同一文書内の無関係な主題語を候補支持へ混ぜない
- Compilerが構造化できた情報をKが構造として優先利用する
- Compilerが構造化できなかった場合は語意味fallbackを残す

## 境界

- 完全HDS-IRは削らない
- R/J/Mへは影響させない
- K未対応scopeは引き続き有向Factへしない
- benchmark固有分岐なし
- 世界知識追加なし

## 受入

まず固定回帰で、構造ありDataから無関係topicが消え、構造なしDataではtopicが残ることを確認する。
外部benchmarkはv0.16構造完成後の受入確認にのみ使う。
