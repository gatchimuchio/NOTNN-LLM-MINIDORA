# MINIDORA 経験学習回復 v0.1

## 目的

現行MINIDORA中核の正常系を変更せず、実行経験から得た再利用可能な作用効果を、従来なら保留になる案件の回復にだけ加算する。

## 不変条件

- 通常実行を必ず先に実行する。
- 通常実行が COMMIT した場合、その実行結果を変更しない。
- 学習経験は実行履歴に確定した状態差から取得する。
- 純粋作用として明示された作用だけを学習対象にする。
- 同一作用定義・同一契約版について、異なる二つ以上の実入力で共通した実測差だけを安定効果候補にする。
- 同一入力の反復だけでは汎化しない。
- 明示失敗が観測された場合、それ以前の成功支持を回復計画へ再利用しない。
- 学習効果は契約効果や正本知識へ書き戻さない。
- 学習回復が COMMIT しなければ、元の通常実行結果をそのまま返す。

## 回復を許可する境界

学習回復は次をすべて満たす場合だけ行う。

- 通常実行が SUSPEND。
- 停止理由が作用不足、予算枯渇、無進展、依存未閉包のいずれか。
- 動的作用供給器を使用していない。
- 観測器を使用していない。
- 停止コールバックを使用していない。
- 実行に含まれる外部作用がすべて純粋作用として明示されている。
- 対象作用について複数実入力から共通実測効果が形成済み。

この境界により、現行の選択問題経路や外部取得経路へ学習期待を無条件注入しない。

## 保持範囲

初版は同一 HDS駆動コア インスタンス内の有限メモリだけを使う。ファイル永続化、大域共有、別端末共有、コード自己変更、未検証の領域横断転用は行わない。

## 非退行構造

通常系と学習回復系を直列に重ねる。

1. 現行通常循環を実行する。
2. COMMIT なら即返す。
3. SUSPEND のうち安全境界を満たす場合だけ、経験由来期待を付けた純粋作用で隔離再実行する。
4. 回復実行が COMMIT なら採用する。
5. それ以外は元の通常実行結果を返す。

したがって学習回復は既存成功を置換せず、従来不成立だった局所領域だけを追加で閉じる。

## 受入

- 空の学習器を接続した既存COMMITが、未接続時の結果と完全一致する。
- 二つ以上の異なる実入力で共通効果を経験した後、従来SUSPENDだった純粋作用案件を回復できる。
- 非純粋作用を含む案件では回復を起動しない。
- 学習状態を初期化すると、学習前の挙動へ戻る。
- 既存全単体試験・再構築CI・公開境界監査を通す。

## 非主張

本仕様は永続学習、無制限自己改善、一般知識の自動獲得、未知作用の自動生成、現行GPQA正本値の向上を主張しない。外部性能値を更新する場合は別途正本評価を実行する。
