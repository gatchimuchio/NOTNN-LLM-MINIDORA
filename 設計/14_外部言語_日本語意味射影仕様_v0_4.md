# 外部言語→日本語意味射影仕様 v0.4

## 1. 目的

外部言語をMINIDORA内部へそのまま持ち込まず、日本語意味正本へ有限射影する境界を定める。

本仕様は翻訳器の仕様ではない。

```text
外部言語表層
↓
外部言語構造の必要部分を認識
↓
日本語の対象・関係・作用・状態へ射影
↓
HDS-IR / MINIDORA計算
↓
必要な外部境界だけ元の言語表層へ戻す
```

## 2. 多言語の位置づけ

外国語は実務上必要な場合のみ扱う。

現在はGPQA、論文、API等の事情から英語処理が実装されているが、英語固有の設計を内部基底へ一般化しない。

将来別言語を扱う場合も、日本語正本へ射影する同じ責任境界を使う。

## 3. 射影対象

必要に応じて次を日本語意味へ保持する。

- 否定
- 量化
- 比較
- 条件
- 様相
- 蓋然性
- 関係種別
- 関係方向
- 未知位置
- 問われている対象型
- 既知対象
- 選択反転
- 時間関係
- 作用主体・作用対象

世界知識の真偽・正答・分野知識・最終採否は扱わない。

## 4. 英語は現行の外部互換実装

例:

```text
Which molecule is least likely to inhibit enzyme X?
```

内部正本:

```text
要求対象 = molecule相当の対象
未知位置 = 始点
関係 = 阻害
既知終点 = enzyme X相当の固有対象
選択 = 反転
```

固有名や分野名を無理に日本語化する必要はない。内部関係・作用・条件の主語を日本語で保持することが目的である。

## 5. 外部検索境界

外部検索時には必要な表層だけ外部言語へ戻す。

```text
内部正本
  関係 = 阻害
  選択 = 反転

外部検索
  predicate = inhibit
```

`predicate` 等が外部APIの固定フィールドである場合は例外として使用できる。

## 6. 禁止

- 外国語の語順を内部関係方向としてそのまま採用する
- 外国語の抽象語を内部概念名として無検査で採用する
- 外国語に一語しかないことを理由に日本語側の分別を潰す
- 日本語に一語で対応しないことを理由に外国語を内部正本へ昇格する
- 翻訳で見つかった欠落を外国語側だけで補完する
- benchmark固有正答をPへ埋め込む
- 世界知識を言語射影層へ混入する

## 7. 意味衝突

外部語と日本語正本の対応が一対一でない場合、外部語へ日本語を従属させない。

```text
外部語A
→ 日本語概念X / Yのどちらか未確定
→ 保留
→ 文脈・作用・関係を再観測
```

必要なら日本語正本側の概念分別を更新する。

## 8. 受入条件

- 外部言語と内部意味正本が別欄で保持される
- 内部関係・作用・状態の主語が日本語である
- 外部互換情報を失わず再検索できる
- 意味不明の外部語を推測で内部概念へ固定しない
- 現行英語評価経路を回帰させない
- 多言語追加で内部正本が複数化しない
