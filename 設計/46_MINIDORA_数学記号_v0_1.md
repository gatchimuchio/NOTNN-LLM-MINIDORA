## 1. 追加する作用

```text
宣言変数 + 形式数式Data + 操作設定
→ 全式の構文・定義域境界を検査
→ 有理数係数の多項式へ正規化
→ 展開・微分・原始関数・代入・恒等比較
→ 再利用可能な多項式Dataと結果
→ 既存合成器の後続計算・採用・表示
```

連立一次方程式は別入口で、各式を正規化して係数を抽出し、正確な行変形で一意解・自由解・解なしを区別する。以前の数値式評価を置き換えず、能力Moduleとして追加する。

## 3. 数式言語とData

宣言変数は0〜8個の一意な名前。日本語名も受理するが、NFKCによる名前の変化を黙って補完しない。未宣言変数、予約語、二重underscore始まりは拒否する。piやe等を暗黙の定数にしない。

許可する表層は整数・十進小数・指数表記、変数、括弧、単項符号、加減乗算、定数による除算、0〜64の整数リテラルによる`**`。`^`を勝手に冪へ置換しない。暗黙の乗算、全角演算子、自由文、比較文、コメント、改行、関数呼出、属性・添字・Pythonコードは未対応として拒否する。

PythonのASTは構文解析だけに使い、入力をexec/evalへ渡さない。小数の値はAST内部のfloatからではなく原文からFractionへ変換する。例: `0.1+0.2-0.3`は正確に0。

式は有理数係数の多変数多項式として保持する。各項は宣言変数順の非負次数列と、正規化した分数文字列である。零項・重複項・非正規順序を持つ構造化Dataは拒否する。生成したDataは後続Moduleへ渡せる。整数・分数を浮動小数点へ自動変換しない。

数式の定数や方程式は推論対象のDataであり、能力合成計画へ埋め込まない。計画に置くのは能力名とData参照先。生成済みコードに定数を埋める設計への変更でもない。

## 4. 定義域と演算

変数を含む分母は式全体を拒否する。`x/x`を1にしてx=0の除外条件を消す処理はない。`0*(1/x)`も評価前に拒否する。`1/(x-x+1)`のように数学的には整理できるものも、この版の構文境界では未対応である。定数分母は正確に計算し、零なら拒否する。

非負整数冪は多項式環の反復積。0乗は空積の1として扱い、`0**0`もこの規約で1。極限における不定形の一般論とは別である。負冪・分数冪・記号指数・指数を計算する式は扱わない。

微分は対象変数に関する偏微分。積分は、その変数について原始関数を一つ構成する。積分定数、または他変数だけの任意関数の加算を含めた一般形を返したとは扱わず、結果の本文とDataにその境界を記録する。

代入は明示した変数への正確な数値代入。同時代入であり、値には数値文字列を指定する。未指定の変数は残す。結果が定数でなければ`定数値=None`。多項式の相殺により全変数を指定せず定数になる場合はその定数を返す。

恒等比較は差の多項式を正規化する。零なら全実数の変数代入に関する恒等、非零なら非恒等。「非恒等」は全点で不一致という意味ではない。特定の数値例で一致しただけで恒等としない。呼出側が宣言していない変数間の制約も仮定しない。

## 5. 線形方程式

`線形を解く(変数, 方程式)`は1〜8変数、0〜16等式を受け取る。各等式は`左辺 / 右辺`を持つ。両辺を多項式として厳密に整理し、次数1以下になった場合だけ扱う。非線形項が厳密に相殺した式は扱えるが、近似的な線形化は行わない。

解の領域は実数。係数・特解・基底は有理数で、自由変数は任意の実数を取り得る。整数条件・不等式・単位・物理的許容範囲は未対応。必要な単位や適用条件を勝手に除いて式だけを解決したことにしないため、この入口には形式等式だけを明示して渡す。

- 一意解: 全変数の値を返す。
- 自由解: 特解、自由変数名、基底を返す。解集合は「特解＋各自由変数値×対応基底」。特解を唯一の解として採用しない。
- 解なし: 元の等式のどの線形結合で`0=非零`を得たか、係数と右辺を記録する。

行簡約の操作と行変換行列を保存する。行変換行列×元拡大行列が返した簡約形に一致することを検査する。可解時は特解を全元方程式に代入し、各基底が全元方程式の同次系を満たすことも確認する。空の方程式集合は全変数が自由であり、勝手に零へ固定しない。

## 6. 報告成立と採用

数学処理の`能力結果.成立=True`は対応範囲の数学報告を作れたという意味。一意解のほか、自由解や解なしの報告も成立する。入力未対応、予算超過、中止、制御故障は報告不成立で、解なしへ読み替えない。

`数学結果採用`は`定数値 / 恒等 / 一意解`の期待を必須指定とする。定数採用は正規化・代入・微分の結果だけを対象にし、比較差の0や積分代表元を元の問いの確定数値へ昇格させない。

既存多段解決器の目的検証にも接続できる。自由解を一意解として採らず、非恒等の候補を恒等として採らない。例題で別候補を渡す場合も明示した候補だけを使い、未知解法の生成とはしない。

## 7. 監査・上限・停止

記録は元の式・操作・設定・正規化した多項式・数値・解区分・行変形を保持する。`数学記録整合`は宣言入力から同じ処理を再実行し、本文と数学Dataの一致を確認する。ハッシュだけを書き直した結果変更は通らない。

同一実装による再計算であり独立した意味評価器ではない。参照資料は合成器が来歴として保持するが、この数学監査は資料の真偽・原式への翻訳の正しさ・参照の真正性を検査しない。元入力ごと整合的に偽造する攻撃への認証でもない。

既定演算数100000、設定上限1000000。数式8192バイト、AST512ノード・深さ32、多項式256項・中間512項・総次数64、有理数の分子分母1024ビット、数値文字列640文字、結果記録1000000バイト。超過時に項・式・前提を剪定せず不成立にする。定数Dataの一つの値変更でも同じ上限を検査する。

停止は開始・終了と一定演算間隔で確認する。計数は論理的な処理単位で、Python内部の命令数・厳密な壁時計時間ではない。上位合成器からModule内部へのコールバック自動伝播は既存契約にないので、合成器経由では呼出前後の停止となる。OS隔離、強制終了、厳密なメモリ制限は提供しない。

## 8. 実行例と範囲

```bash
python tools/数学記号デモ.py
python tools/数学記号デモ.py --値 731
python tools/数学記号デモ.py --モード 一意解
python tools/数学記号デモ.py --モード 自由解
python tools/数学記号デモ.py --モード 解なし
```

デモは`(x+1)**3`を微分してから代入する。x=2なら27。x=3で微分工程を外す対照では64、微分ありでは48になり、工程の後状態が後続計算へ使われることを確認する。
