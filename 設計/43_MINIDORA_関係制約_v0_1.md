日付: 2026-09-10
基点commit: `1c62684dca6f693b7db662788f2e5a71d0e5b0b8`
対象: 開発一覧⑦の、同一尺度の差分関係に対する推論と比較。

## 1. 追加する作用

```text
構造化された関係問題、または既存の数値証拠報告
→ 同一属性・単位・条件・時点の差分制約
→ 前提の充足可能性を検査
→ 問い／問いの否定を仮に追加して再検査
→ 導出／反証／未確定／前提矛盾／保留
→ 根拠制約・原文位置付きの報告
→ 確定判定だけを採用して後段Moduleへ渡す
```

`A−B≧3、B−C≧2`から`A−C≧5`を導く。結論を入力へ直書きする必要はない。一つの関係を除くと未確定へ変わり、矛盾する関係を加えると前提矛盾へ変わる。

既存の証拠比較が「範囲のみ」とした報告も利用する。例えば資料上の`A≧120、B≦100`はA・Bそれぞれの値を一点に決められないが、`A>B`は導ける。一意な値が採用できることを比較可能性の必要条件にしない。

これは明示前提からの数値関係推論であり、Coreの置換、世界の事実認定、一般的な自然言語理解ではない。

## 2. 型と責任

| 型・Module | 責任 |
|---|---|
| `関係式` | `左項−右項 比較 差`。識別子、変数名、比較、正確な数値文字列を保持。 |
| `関係問題` | 変数、前提制約、問い、共通属性・単位・条件・時点、未解釈情報、原文参照。 |
| `関係根拠` | 前提制約IDを参照本文の文字範囲へ対応づける。 |
| `数値関係化Module` | 既存証拠報告を元資料から再計算してから、同一尺度の差分制約へ接続する。 |
| `関係制約Module` | 差分制約の整合性と各問いの含意を判定する。 |
| `関係判定採用Module` | 指定した問いが明示期待の「導出」または「反証」で確定した場合だけ後段へ渡す。 |

`関係問題`は推論対象のDataである。実行計画Pに入力事実を埋め込むのではなく、既存合成器にはDataの参照先だけを渡す。

属性・単位・条件・時点は問題全体の共通スコープ。直接構造化入力の意味付けと、全制約に同じ尺度を適用してよいかは呼出側の宣言責任である。原文範囲の一致だけでは、その文章を正しく制約化した証拠にはしない。

## 3. 演算の範囲

実数変数に関する有限個の差分制約の連言を対象とする。定数は整数・有限小数・有理数を文字列で渡す。浮動小数点値は受理せず、`Fraction`で正確に加減・比較する。比較は`一致／不一致／以下／未満／以上／超`。

数値上界と厳密性を別に保持したグラフ閉包を求める。辺`y→x`の上界cは`x−y≦c`を表す。経路の数値は加算し、一つでも厳密な不等号があれば結果も厳密。微小な浮動小数点epsilonや許容誤差で置き換えない。負の閉路、または上界0の厳密閉路があれば前提は同時に成立できない。

非等式`x−y≠c`は、凸な差分不等式の可解領域が`x−y=c`に固定されているかを調べる。固定されていれば不整合。実数上では、非空の凸多面領域が有限個の超平面の和集合に覆われるなら、そのうち一つの超平面に含まれる。そのため有限個の非等式は、この固定等値検査で扱える。整数領域へは転用しない。`0≦x≦1、x≠0、x≠1`は本実装では可解であり、整数問題とは違う。

一般的な論理和、量化、非線形制約、整数制約、確率、誤差分布、集合包含、因果は今回の対象外。SMT-LIBのQF_RDLと重なる差分関係を扱うが、SMT-LIB入出力や同論理全体への適合を実装したとは主張しない。

## 4. 判定と根拠

最初に前提だけの整合を確認する。不整合な前提から任意の結論を導いたことにしない。

| 判定 | 意味 |
|---|---|
| 導出 | 前提と問いの否定が同時に成立しない。問いは全ての許容値で成立する。 |
| 反証 | 前提と問いが同時に成立しない。問いの否定が全ての許容値で成立する。 |
| 未確定 | 問いが成立する場合と成立しない場合が残る。任意の一例・順位を選ばない。 |
| 前提矛盾 | 前提全体が同時に成立しない。問いの採用は全件止める。 |
| 保留 | 上流の未解釈・資料不足等が残り、推論結果を確定しない。 |

矛盾検査に使った前提ID集合と仮定を報告する。仮定IDには予約接頭辞`@`を使い、元前提と混同しない。原文対応があれば、その前提を資料へ追跡できる。返す集合は十分な競合根拠であり、最小矛盾集合ではない。未確定時に具体的な代入モデルを返す機能はない。

判定器の`能力結果.成立=True`は報告の作成成功。前提矛盾や未確定の報告も作成する。後段へ確定判定が必要な場合は採用Moduleを明示接続する。既定は「導出」のみ。反証を条件にする場合も明示指定する。

## 5. 既存証拠報告への接続

既存の証拠報告を同じ要求・参照本文で再比較し、hashだけでなく内容の一致を確認する。対象ごとに一つの適用群を要求する。複数群が未選択、属性・正規化単位・条件・時点のいずれかが不一致なら、混合を拒否する。

同じ比較群の各数値主張を`対象−@基準点 比較 数値`へ移す。`@基準点`は全対象共通の原点。差分系は全体を平行移動しても変わらないため、原点を0に固定する表示上の選択は比較に影響しない。予約対象名との衝突を拒否する。

範囲のみという理由は比較を止めない。一方、未解釈記載・条件欠落・資料系統不足等は問題の未解釈情報へ残し、値を採用しない。数値記載自体の競合は制約系へ渡し、前提矛盾として検出する。否定・厳密不等号・単位換算の情報は保つ。

「条件未記載同士」は同じ未記載の比較スコープとして扱うだけで、現実に同一条件だったと認定しない。上流の未観測情報や誤読は本器だけでは補償できない。自由文を勝手に関係へ変換する新規文法は追加しない。

## 6. 整合・予算・停止

24変数、128前提、16問い、256根拠リンク、入力記録1000000バイト、出力記録1500000バイト。差の表記は分子・分母または整数部・小数部各64桁以内。既定演算数上限500000。上限で未処理前提を削って判定を返さない。

直接呼出では停止コールバックを一定演算間隔と終了直前に確認する。合成Moduleでは既存合成器の呼出前後の停止検査を使用し、外部作用は持たない。プロセスを強制中断する機能や厳密なメモリ隔離はない。

入力を複製し、各結果の条件・時点を採用出力にも残す。関係記録の監査は元の制約から同じ処理を再実行する。hashを作り直した判定改変も検出するが、元前提の真正性を証明しない。同じアルゴリズムの再実行とは別に、試験では変数消去による独立計算も対照する。

## 7. 検証と利用

```bash
python tools/関係制約デモ.py
python tools/関係制約デモ.py --関係欠落
python tools/関係制約デモ.py --矛盾
python -m unittest discover -s tests -p 'test_関係制約*.py' -v
```

通常はA−C≧5が導出される。関係欠落では未確定、逆の関係追加では前提矛盾になる。人工入力の局所対照で、GPQAやGPT-4比較ではない。
