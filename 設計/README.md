# MINIDORA 設計正本ガイド

`設計/` は現行MINIDORA実行系の局所インターフェース、受入条件、互換境界を保持する。

## 公開境界

公開設計書は次だけを扱う。

- 入力と出力
- 前提条件
- 失敗条件
- 互換性
- 検証条件
- 外部評価との分離

内部理論の完全な抽象定義、上位参照先、固定参照commit、内部抽象から実装への完全対応表は公開しない。

局所規定:
- [`00_日本語基底規定_v1.md`](00_日本語基底規定_v1.md)
- [`01_日本語正本語彙_v1.md`](01_日本語正本語彙_v1.md)

外部の言語模型成立条件は `LLM-Constitutive-Specification` を参照する。

## 現行実装

現行統合実行系の互換契約ファイル名は `60_MINIDORA_HDS自律接続_v3.md`。
この公開ファイルは実装境界だけを示し、内部理論の定義を再掲しない。

MINIDORA30 / MINIDORA80 / 現行統合実行系の評価系列は混同しない。
性能値は各評価正本の実測値だけを使用する。

## 設計文書の扱い

歴史的なファイル名・版名は再現性のため残る場合がある。
ただし、旧版差分を内部理論の変更履歴として説明しない。

新規設計文書は `../PUBLICATION_BOUNDARY.md` に従い、局所契約だけを公開する。
