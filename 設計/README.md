## 現行構造

```text
MINIDORA v0.5
├─ 厳密言語模型核
├─ 能力模型核
├─ 計算実行器
├─ HDS Compiler
└─ 後段HDS判断門
```

厳密言語模型核と能力模型核を同一視しない。

## 候補選択経路

```text
自然言語 / Data
→ HDS Compiler
→ MINIDORA能力模型核
→ MINIDORA出力
→ HDS判断主体
```

保留・拒否後は現行経路では差し戻さない。

## 変更規則

- 日本語を内部意味正本とする。
- 外国語は実務上必要な外部互換境界だけで使う。
- 外部語から内部概念名を決めない。
- 候補得点を厳密言語模型確率へ変換しない。
- GPQAを言語模型成立証拠へしない。
- 厳密言語模型成立からLargeを自動導出しない。
- HDS型を厳密言語模型核へ逆流させない。
- Legacy評価・構文化を現行正本へ無言復帰させない。
- 設計変更時は実装・試験・README・評価解釈を同期する。
