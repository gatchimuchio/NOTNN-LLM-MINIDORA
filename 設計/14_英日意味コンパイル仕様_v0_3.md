# 英日意味コンパイル仕様 v0.3

## 1. 目的

MINIDORAの内部意味正本は日本語である。一方、GPQAを含む外部Data・API・論文・技術文書には英語が多い。

したがって英語入力を扱うとき、英語表層をそのまま内部認知へ持ち込むのではなく、**日本語正本の意味構造へ有限射影する境界**を置く。

本仕様でいう英日意味コンパイルは、英語文章を自然な日本語文章へ翻訳する処理ではない。

```text
外部英語表層
    ↓
英語言語構造の認識
    ↓
日本語正本の意味フレーム
    ↓
HDS-IR / Cの意味計算
    ↓
R境界では必要な検索意味だけ英語表層へ戻す
```

## 2. 背景

共有言語基底P v0.2で、英語の語形・派生語・一般関係を日本語正本へ接続した。

例:

```text
inhibited / inhibition / inhibitory
    ↓
inhibit
    ↓
阻害
```

この変更だけでGPQA Diamond実測は19/198から25/198へ改善した。

この結果は、世界知識をPへ追加しなくても、質問の意味をより正確に認識することでR検索・証拠照合へ到達しやすくなることを示した。

v0.3では単語単位だけでなく、質問構造そのものの変換損失を減らす。

## 3. 責務

英日意味コンパイルは次を扱う。

- 否定
- 量化
- 比較
- 条件
- 様相
- 蓋然性
- 関係種別
- 関係方向
- 未知端点の位置
- 問われている対象型
- 既知端点
- 選択反転

世界知識の真偽、正答、分野知識、最終採否は扱わない。

## 4. 関係質問の正本化

例:

```text
Which molecule is least likely to inhibit enzyme X?
```

は、内部で次へ射影する。

```text
要求型 = molecule
未知位置 = 始点
関係 = 阻害
既知終点 = enzyme X
選択意図 = 反転
```

全文を日本語文へ翻訳する必要はない。

R検索時だけ、候補を未知端点へ代入して外部英語表層へ戻す。

```text
Compound A inhibit enzyme X
Compound B inhibit enzyme X
...
```

## 5. 受動態

英語の語順を内部関係方向へ誤投影しない。

```text
Which protein is inhibited by compound X?
```

は、

```text
compound X --阻害→ 未知protein
```

とする。

`protein --阻害→ compound X` とはしない。

## 6. 日本語意味正本と外部検索表層の分離

内部意味と外部検索語を同じ座標へ混ぜない。

```text
内部:
  関係 = 阻害
  選択 = 反転
  未知位置 = 始点

外部R境界:
  predicate = inhibit
```

日本語正本語を英語検索queryへ無差別に混入させない。
英語検索表層を内部意味正本へ昇格させない。

## 7. 安全境界

次を禁止する。

- GPQA問題番号・gold・正答ラベルを用いる
- benchmark固有の問題文分岐を作る
- protein / quantum / enzyme 等の分野知識をPへ格納する
- 名詞共起だけで有向関係を確定する
- 関係語が存在しない質問から関係を捏造する
- 英語語順をそのまま関係方向として扱う
- 日本語意味正本をR検索queryへそのまま混ぜる
- 外部検索語を内部正本として扱う

## 8. HDS Compilerとの関係

英日意味コンパイルは公開HDS Compilerの前段Projectionとして動作する。

```text
外部入力
  ↓
基礎HDS Compiler
  ↓
英日意味Projection
  ↓
英語明示関係Projection
  ↓
公開HDS Front-End
  ↓
HDS-IR
```

英日意味ProjectionはHDS本体の上流理論を公開するものではない。
公開されるのは、英語表層を公開HDS-IR契約へ有限射影する通常のRuntime実装である。

## 9. C / Rへの作用

Cは日本語正本の意味フレームで関係を比較する。
Rは外部情報取得のため英語検索表層を使う。

```text
C: 何を意味するか
R: 何で検索するか
```

この二つを分離する。

## 10. 受入条件

- `least likely` を選択反転として保持できる
- 能動関係質問の未知始点を抽出できる
- `What X does Y produce?` を未知終点へ射影できる
- 受動態の関係方向を正規化できる
- 候補検索を `候補 + 関係 + 既知端点` へ落とせる
- 非関係質問で有向関係を生成しない
- 世界知識を追加しない
- v0.2能力を退行させない
- 通常CIを通過する
- GPQA Diamond実測で性能を確認する

## 11. 性能解釈

比較基準はv0.2のGPQA Diamond実測とする。

```text
correct = 25 / 198
answered = 123
answered accuracy = 20.33%
SUSPEND = 75
```

R取得はrun間で変動するため、スコア単独で因果を確定しない。
ただし、質問意味射影の改善が検索query・回答率・回答時正答率・SUSPENDへどう作用したかを同時に観測する。
