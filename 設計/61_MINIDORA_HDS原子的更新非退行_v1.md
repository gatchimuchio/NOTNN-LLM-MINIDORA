# MINIDORA HDS原子的更新非退行 v1

## 目的

HDS通常循環で、同一作用が同一成果を読みながら更新する read-modify-write を原子的更新として扱う。
MINIDORA30互換水準を下回ったGPQA同run比較で、追加参照作用が自身の出力状態を即時失効させ、後続再評価より同一作用再実行を優先していた失敗署名を修正する。

## 規則

- 同一作用内で同時に読取・産出されたノードは、旧版読取値から同時産出物への自動依存元にしない。
- 読取証明そのものは前状態署名として保持し、古い入力からの作用結果を採用しない。
- 後続作用が更新後成果を読む場合は、更新後ノード署名から通常の依存を形成する。
- 後から成果が変更された場合、後続再評価結果・回答状態は従来どおり失効する。
- GPQA固有規則、gold、固定参照資料はコアへ持ち込まない。

## 監査結果

RMW修正により、旧版で見られた `追加参照1 → 追加参照1` の自己再実行は解消し、後続再評価へ進むようになった。
全リポジトリCIも通過した。

一方、2026-09-17のRMW修正後LIVE_ONLY同run比較は MINIDORA30互換25/198、並列HDS-v3 24/198であり、並列置換だけでは性能下限を保証できなかった。
これは追加LIVE参照の差と、既存承認結果をHDS側が別結果へ置換できる構造が残るためである。

このため性能下限の最終保証は `62_MINIDORA_HDS非退行包絡_v1.md` に分離し、MINIDORA30成立結果を既知の下限として保持する。

## 受入条件

1. 原子的更新作用を同じ入力段階で無意味に二重実行しない。
2. 更新直後に後続再評価へ進める。
3. 後続成果の依存失効は維持する。
4. 全リポジトリCIを通過する。
5. 並列HDS-v3の単独性能差は観測値として保存し、性能下限そのものは非退行包絡で保証する。
