# 未確定作業状態と再作用 v1

- 日付: 2026-08-26
- 対象: MINIDORA v0.4 HDS選択Runtime
- 根拠: `構文化/LLM横断_能力成立作用構文化_v1/` および `構文化/K3_能力成立作用構文化_v1/`
- 状態: P0実装契約
- ライセンス: CC-BY-4.0

## 1. 目的

現行MINIDORAの確定K境界を維持したまま、確定前の未確定関係を即廃棄せず、同一request内で再作用・再照合できる領域を追加する。

この変更はLLM模型核の成立条件を変更しない。HDS選択Runtimeの能力作用を拡張する。

## 2. 変更前

```text
参照Data
↓
HDS-IR
↓
証拠台帳 / K
↓
候補証拠化
↓
候補横断調停
↓
J
```

`未確定 / 未観測 / 矛盾 / 留保 / semantic_loss` を含む証拠は台帳には保持されるが、通常の候補比較からは阻害される。候補横断調停で寄与0となった証拠にも後段再作用経路がない。

## 4. Gate分離

### 4.1 確定Gate

- canonical Kへ世界事実として採用してよいか
- 最終Jへ進めてよいか
- unknown / contradiction / semantic loss停止を維持する

### 4.2 寄与Gate

- 未確定作業関係を後段で再利用するか
- どのcheckpointを再活性するか
- 候補共同状態へ再作用するか

寄与Gateは真偽を確定しない。

## 5. P0実装

### 5.1 Working Relation Store

HDS証拠台帳の全極性・全修飾viewから、各証拠を作業関係として保持する。

保持項目:

- fact id
- source id
- predicate / args
- polarity
- qualifier
- support state
- contribution value
- blocking state
- reuse count

### 5.2 一時証拠化条件

v1では安全側に限定する。

1. `hds_relation_*` の有向関係である。
2. 正極性である。
3. 無修飾である。
4. 通常証拠としては阻害されている。
5. 同一関係を二つ以上の独立出典が保持する。
6. 同一predicate/argsの反対極性関係が存在しない。

条件を満たした場合もcanonical Kへ昇格しない。元出典ごとにrequest-local Factを作り、別cloneのHDS証拠台帳へだけ投入する。

単語・座標の共起だけでは一時証拠化しない。

### 5.3 checkpoint

最低限次を記録する。

- `DATA_INGESTED`
- `CANDIDATE_INITIAL`
- `WORKING_RECONCILED`
- `CANDIDATE_RECHECK`

checkpointは作業関係ID集合と候補得点状態を保持する。v1では同一request内の再作用監査に使用する。

### 5.4 候補共同状態

各候補について、

- own score
- maximum competitor score
- margin
- independent source count
- distinctive source count

を同じ状態として保持する。

候補を孤立した最終scoreだけとして扱わず、再照合前後の相対差を記録する。

### 5.5 再作用結果の採用

一時証拠が存在するときだけ二巡目を実行する。

- 初回が明確なdirect relation verifiedなら初回を維持する。
- 初回SUSPEND、二巡目APPROVEなら二巡目を採用可能。
- 同一回答なら二巡目を採用可能。
- 回答が変わる場合は、独立出典・識別一致出典・margin・根拠事実数・scoreの順で二巡目が明確に強い場合だけ変更する。
- 二巡目がSUSPENDなら初回APPROVEを失わない。

## 6. 不変条件

1. canonical Kへ作業証拠を自動昇格しない。
2. gold labelを参照しない。
3. GPQA固有語・正答パターンを実装しない。
4. negative / qualified relationをpositive unqualifiedへ変換しない。
5. 反対関係が存在する場合は正関係を作業証拠化しない。
6. 同一入力・同一Dataで決定論的に再現する。
7. 模型核 `src/minidora/模型.py` へHDS依存を逆流させない。
8. 計算実行器 / Compute IRへこのRuntime責任を混入しない。

## 8. P0の非対象

次は第二段以降とする。

- 条件付き関係の条件scope照合による再活性
- negative relationの反証寄与を候補差へ明示加算
- 専門作用routing
- Data/experienceからの関係形成工程
- modality adapter
- 長期task state / agent harness

1. 新規作業状態unit testがPASSする。

3. 1出典だけでは再作用による確定を行わない。
4. 反対関係があれば正関係を再活性しない。
