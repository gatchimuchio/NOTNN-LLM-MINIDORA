# HDS-IRコンパイラ仕様 v0.1

## 1. 目的

MINIDORAの自然言語境界を、表層パターンから直接Pへ変換する方式から、HDSによって意味をHDS-IRへ射影し、その局所閉包をLayer-0実行Pへloweringする方式へ変更する。

```text
自然言語 / 外部Data
  ↓
HDSコンパイラ
  ↓
HDS-IR（座標・関係・暫定性・由来・残差・意味作用履歴）
  ↓
局所閉包
  ↓
Layer-0実行P
  ↓
結果
  ↓
HDS全場への帰還
```

## 2. 正本境界

HDS-IRはHDS rev4.1の有限Projectionであり、HDS Nativeそのものではない。

- 九座標を最終スキーマへ固定しない。
- 座標型は文字列で開放し、追加座標を許容する。
- `semantic_discard_tolerance = 0` と `relation_discard_tolerance = 0` を実装原則とする。
- 表現不能・未分別・競合は消さずResidualへ保持する。
- 原文、正規化文、由来、意味作用履歴を保持する。
- IRが局所閉包できない場合、Pを捏造せず保留する。

## 3. HDS-IR

主要Record:

- `HDS座標`：対象・状態・文脈・目的・作用・境界等を開放型座標として保持する。
- `HDS関係`：座標間の依存、入力、作用、結果、同一性、矛盾等を保持する。
- `HDS残差`：未分別、意味損失、未知境界、競合を保持する。
- `HDS意味作用`：正規化、意味理解、射影、分解、実装等の変換履歴を保持する。
- `HDS実行核`：現行Layer-0へlowering可能になった局所閉包だけを保持する。

## 4. PとDataの分離

```text
P = どう処理するか
Data = 何を意味し、何について処理するか
```

`足す`、`和`、`plus`等は別Pではない。語義Dataを介して同じ`加算`作用へ射影する。

外部参照Dataも同じHDS意味空間へ統合する。意味メタデータが存在する場合、対象・属性・値・時点・範囲等を座標化する。同一意味スロットで値が競合した場合だけ矛盾として保持する。意味メタデータがない二つの文字列へ意味を捏造しない。

## 5. Legacy境界

`自然言語器`は互換APIとして残すが、意味処理実体を持たない。内部では`HDSコンパイラ`へ委譲する。

## 6. 現行適合範囲

v0.1は次をHDS-IRへ射影して実行できる。

- 明示数式・比較
- 日本語の加算・減算・乗算・除算の同義表現
- 日本語比較表現
- 文字数計数
- 外部参照
- 意味メタデータ付き参照Dataの矛盾分別

一般自然言語全体の意味コンパイル完了は主張しない。未対応入力はResidualまたは外部参照へ残し、意味を推測で補完しない。
