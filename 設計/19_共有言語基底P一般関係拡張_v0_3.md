# 共有言語基底P 一般関係拡張 v0.3

## 1. 位置づけ

本仕様は `13_共有言語基底P仕様.md` v0.2 を基礎とする差分正本である。
v0.2の文字体系・日本語基底・既存11一般関係を維持し、主要外部接続言語である英語の分野横断関係を追加する。

採用時の共有言語基底版は `v0.3` とする。

## 2. 目的

次の英語を単なる語集合として扱わず、日本語正本の関係意味へ接続する。

```text
bind / bound          → 結合
interact / interaction → 相互作用
consist / compose     → 構成
belong                 → 所属
locate / location     → 位置
derive / derivation   → 由来
```

これらは世界についての個別知識ではなく、対象間の関係を表す言語要素である。

## 3. 屈折・派生語

例:

```text
binds / bound / binding       → bind
interacts / interacted / interaction → interact
consists / consisted          → consist
composed / composition        → compose
belongs / belonged            → belong
located / location            → locate
derived / derivation          → derive
```

派生名詞だけから有向関係を確定しない。
意味照合では基本形と `rel:<日本語関係>` anchorを共有する。

## 4. 明示関係構文

高確度の明示構文だけをHDS関係へ射影する。

```text
A binds to B            → A --結合→ B
A interacts with B      → A --相互作用→ B
A consists of B         → A --構成→ B
A is composed of B      → A --構成→ B
A belongs to B          → A --所属→ B
A is located in B       → A --位置→ B
A is derived from B     → A --由来→ B
```

`is derived from` はcopular専用構文で扱い、active規則が `A is` を始点として二重生成しない。

## 5. 関係質問

英日意味コンパイルの関係句に `of` を追加し、共有Pの関係概念を使って未知端点を構造化する。

```text
Which protein interacts with receptor X?
→ 未知始点=protein / 関係=相互作用 / 既知終点=receptor X

Which structure consists of component X?
→ 未知始点=structure / 関係=構成 / 既知終点=component X
```

R境界では日本語正本関係ではなく `interact with` / `consist of` 等の英語検索述語へ戻す。

## 6. 安全境界

- 名詞共起だけから関係を作らない
- 世界知識・分野固有事実をPへ追加しない
- benchmark固有語・gold・問題番号を使わない
- 関係語の派生名詞だけから有向関係を作らない
- `A is derived from B` を `A is --由来→ B` と誤分解しない
- v0.3英日意味正本化の責務を変更しない
