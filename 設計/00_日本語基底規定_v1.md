# 日本語基底規定 v1

## 0. 位置づけ

本規定はMINIDORAにおける言語使用の局所正本である。

最上位の理論・言語規定は `gatchimuchio/cognitive-engineering-foundations` に置く。

参照正本:

- `README.md`
- `PUBLICATION_POLICY.md` v1.2.1
- `00_認知工学とは何か_v0_3_ja_en.md`
- `01_情報工学における言語基底論_v0_3_ja_en.md`
- 参照commit: `60131da52ba7931ed7f82c7648a74ac790f50d08`

本規定はそれらをMINIDORAの構文化・設計・実装・監査へ射影したものであり、上位理論を置き換えない。

## 1. 原則

> **MINIDORAにおける基本言語・規定言語・意味正本・設計言語・構文化言語・監査言語・内部構造名は日本語とする。多言語は実務上やむを得ない場合に限って局所的な例外として使用する。**

```text
日本語で対象化
→ 日本語で差異化
→ 日本語で関係化
→ 日本語で構造化
→ 日本語で判断・監査
→ 日本語正本を成立
→ 必要な外部境界だけ多言語へ射影
```

外国語を第二基底、並列正本、内部意味の主語として扱わない。

## 2. 日本語を正本とする対象

原則として次を日本語で保持する。

- 仕様・設計・規定
- 構文化結果
- 内部意味概念
- 状態名
- 作用名
- 関係名
- 境界名
- 採否名
- 監査語彙
- JSON等の内部構造化データの鍵・区分値
- 実装上の独自識別子
- 試験名
- ログの意味区分
- 文書名・成果物名

既存実装・外部規格に拘束されない独自名称を英語で新設しない。

## 3. 多言語を認める例外

次は実務上必要な範囲で例外を認める。

1. Python等のプログラミング言語予約語・標準構文
2. HTTP、JSON、Git、SHA-256等の外部規格・形式名
3. 外部APIが要求する固定フィールド・固定値
4. 既存ライブラリ・外部関数・外部型の正式名
5. 外部模型・製品・論文・方式の固有名
6. URL、commit hash、版識別子、外部言語コード
7. 外部検索・国際公開・応募等で必要な外国語表層
8. 原典確認のため保存する引用・外部原語

例外は内部正本へ昇格させない。

## 4. 外部原語の扱い

外部原語を観測した場合、原語をそのまま内部概念名にしない。

```text
外部原語
↓
対象・作用・関係・状態・境界へ分解
↓
日本語意味正本へ射影
↓
必要なら「外部原語」欄へ対応だけ保存
```

例:

```text
routing
→ 経路選択 / 参照先選択 / 作用先選択

recurrent state
→ 持続状態 / 系列間継承 / 継続更新

harness loop
→ 外部実行循環 / 結果帰還 / 次作用選択
```

どの日本語概念へ射影すべきか確定できない場合は、外部原語のまま内部概念を新設せず保留する。

## 5. 外部言語コードとの分離

`ja`、`en`、`zh` 等は外部互換用の言語識別コードである。

```text
規定言語 = 日本語
基底言語 = 日本語
外部互換コード = ja
```

を分ける。

`ja`という文字列を「内部意味の基底そのもの」と扱わない。

## 6. 構文化規則

LLM等の外部対象を構文化するときは、公開資料の語彙体系を内部座標へそのまま持ち込まない。

最低限、次を日本語で分別する。

- 何が保持されるか
- 何が変化するか
- 何が後続へ渡るか
- 何が参照先を変えるか
- 何が経路を変えるか
- 何が計算量を変えるか
- 何が再参照されるか
- 何が再結合されるか
- どの時間・作用尺度の循環か

外部方式名は根拠・対応語として残してよいが、構文化の主語にはしない。

## 7. 監査規則

日本語基底の監査では、単なる日本語文字率を評価しない。

確認するのは次である。

- 内部概念の主語が日本語か
- 外部原語が意味分類を支配していないか
- 日本語で区別できる差を外来語一語へ圧縮していないか
- 外部語の意味不明箇所を推測補完していないか
- 多言語例外が局所境界に閉じているか
- 日本語原典と外部表層が衝突した場合に日本語正本へ戻れるか

翻訳・外部接続で意味欠落が見つかった場合、外国語側で補完せず日本語正本を先に再監査する。

## 8. 再開放

本規定も認知工学の自己適用から除外しない。

現在条件では日本語基底を強く固定する。将来これを変更するには、単なる国際慣行や実装都合ではなく、意味構造保持・操作効率・実測において現行判断を崩す具体的観測を要求する。
