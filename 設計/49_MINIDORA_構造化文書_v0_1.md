# MINIDORA 文書・構造化Data処理 v0.1

日付: 2026-09-11
基点commit: `e722464c2b7c3e2747be9bfab03ab75e47ccab6f`

## 1. 作用と境界

```text
原文 + 明示した形式・CSV設定
→ 型・階層・行列と原文位置を保持した構造
→ 明示した位置・列・行の選択／型検査／形式変換
→ 型付き値、未選択位置、元の原文、操作履歴
→ 明示した単一値の取出 → 既存能力・HDSへの入力
```

全文から数字を拾うだけの処理と、指定した表の列・行・階層を使う処理を分離する。列名・位置・型・対象形式は上位から渡すDataであり、計算Pには値を埋め込まない。意味的にどの欄を選ぶべきかは本Moduleで推測しない。

Core、HDS Compiler、既存合成器・科学Module・文書操作・多段解決・長文脈・GPQA正本・標準チャット入口・GUI-Shellは変更しない。新規依存、外部通信、ファイル読書き、exec/evalは追加しない。

## 3. 原文と型

入力はUnicode文字列で、形式は`JSON / CSV`を明示する。文字コード推定・自動形式判定はしない。BOM付き入力は上位の明示的な文字コード処理を求めて保留する。PDF、DOCX、XLSX、XML、Markdown文書構造は今回未対応。

JSONの各節点は`型 / 値`で表す。型は対象・配列・文字列・数値・真偽・空値。数値の値欄は検証済みのJSON数値表記を文字列で保持するため、文字列型との区別は型タグに依存する。`120`、`"120"`、`true`、`null`、欠落項目を同一視しない。大きい整数や小数をfloatへ変換せず、`9007199254740993`、`1.2300`、`-0`などの表記も保持する。

JSON文字列のescape復号には標準パーサを使い、複合構造・位置・上限を本Moduleで検査する。重複キーは復号後の名前で検査し、後の値で上書きしない。NaN、Infinity、末尾の追加文、コメント、不正な末尾カンマ、孤立サロゲートを拒否する。全式の構文を読んだ後で選択するので、未選択部分の構文不正を捨てない。

CSVはカンマかタブ、見出しの有無を明示する。外側の行区切りはLF/CRLF。引用内の改行・カンマ・二重引用符を復号し、空欄・前後空白・先行零を保持する。全セルは文字列型とし、数値・日付を推測しない。不揃いな列数を空欄で埋めたり余剰列を落としたりしない。見出しありでは空見出し・同名列を拒否する。空行も黙って無視しない。

CSVの構造はデータ行の配列で、各行はセル配列。見出しは別フィールドで保持する。原文位置は渡された文字列のPython文字位置であり、UTF-8バイト位置・トークン位置ではない。引用セルの範囲には原文の引用符が含まれる。

## 4. 操作契約

各操作は明示設定を要求する。未知設定は無視しない。

### JSON選択

`{"位置":"/items/0/金額"}`。JSON Pointerの空文字列は根、`~0`はチルダ、`~1`はスラッシュ。URI fragmentやワイルドカードではない。配列は先行零のない非負整数添字とし、欠落位置・負添字・`-`・不正escapeを拒否する。対象のキー`"01"`は配列添字と区別する。

選択後の根は指定した部分構造となる。全ての残存節点の原本位置とキー位置を再対応させる。複数回の選択でも最初の原文へ戻れる。

### CSV選択

`{"列":["金額"],"行":[0]}`。列は名前または0基点の番号、行は0基点の番号配列。見出しなしでは列番号を使う。行がnullなら全行、空配列なら0行を明示したことになる。指定順で再配置し、重複行列・欠落行列・bool添字を拒否する。見出しなしの0行は列構造をCSVで保持できないため、出力を保留する。

### 型検査

`{"規則":[{"位置":"/金額","型":"数値","必須":true}],"未指定許可":false}`。

必須位置の有無と型を検査する。任意項目がない場合は通るが、存在する項目の型違いは通らない。未指定許可falseでは、いずれの規則にも覆われない末端を拒否する。対象・配列を規則に指定した場合はその部分木全体を対象として認めるので、子の型まで検証したことにはならない。

これは局所の明示型契約であり、JSON Schemaへの対応を主張しない。意味的整合、値域、単位、欄同士の因果関係は検査しない。

### 形式変換

CSV→JSONは`{"出力":"JSON","行表現":"対象"}`または`"配列"`。対象形式には見出しが必要で、見出しをキーへ移す。セルは数値らしく見えても文字列のまま。配列形式で本文から外れる見出しも、原本と未選択見出しへ残す。

JSON→CSVは`{"出力":"CSV","列名":["番号","値"]}`。対象配列の各行が指定列と正確に同じキー集合を持ち、全値が文字列の場合だけ変換する。欠落欄を空文字にする、nullを空欄にする、数値を文字列にする、複合構造を潰す処理はしない。空の対象配列でも列名が明示されれば見出しだけを返せる。

CSV出力は標準writerを使いCRLFで構成する。出力セル・見出しが空白除去後に`= / + / - / @`で始まる場合、または先頭がタブ・改行の場合は、外部表計算での式解釈リスクとして保留する。引用符だけで安全とはみなさない。値の改変で回避しない。このため負数の文字列も出力が保留される。全表計算製品に対する安全保証や一般的な無害化機構ではない。読取・JSON出力ではこの値も単なるDataとして保持する。

### 値取出

`{"型":"文字列"}`等で単一値の型を指定する。構造全体を文字列へ自動変換せず、指定した末端の本文だけを後段へ渡す。空文字は空文字、空値は`null`の表記となり、Dataには型を保持する。既存の抽出器が空本文を受理するかは別の契約である。

## 5. 原本・省略・変換の記録

結果は原本（原文と読取設定）、操作列、現在の型付き構造、現在位置から元位置への対応、キー・見出し対応、未選択末端位置、未選択見出しを保持する。

`全原値保持`は原本の末端値が残っているかのフラグで、キー・見出し・空白・引用符・完全な文脈を含む同一性ではない。選択で省略した箇所は原本に残るが、下流へ渡す本文には含まれない。選択が問いに必要な条件や留保を落としていないかは、上位の依存宣言・選択・意味監査の責任である。

例えば金額欄だけを選ぶと備考欄も省略され得る。本Moduleはその省略を記録するが、備考の意味を解釈して自動同伴させるものではない。原文と構造を保持していることを、全文の意味理解や無損失要約と同一視しない。

読取・操作の成功は形式処理の成功。内容の真偽や選択の適切さの認定ではない。見出しや資料中に命令文があっても実行権限は生じない。出力は文字列Dataとして扱い、HTMLとして表示する場合のescapeや、ファイルを開く場合の許可は別責任。

## 6. 再構成監査と接続

`文書記録整合`は最初の原文を再度読み、保存された操作列を再実行して本文とDataを照合する。選択値・型・原文位置・省略情報を書き換え、hashだけ付け直した記録は通らない。同一実装による再検査であり、パーサ自体の誤りや、元資料を含む整合的な偽造の真正性を検証するものではない。

参照資料は既存合成器により原文のまま伝播する。原典本文を選択値や変換後のJSONで上書きしない。本文のどの範囲が原典のどの意味を表すかはこの形式監査とは別である。

接続例はCSV読取→列行選択→JSON化→単一セル選択→値取出→既存数値抽出。列を変えれば番号、行を変えれば別の値が渡る。型検査を既存多段解決の目的検証にし、長文脈保存から戻した原文も処理できる。

実HDS試験では選択した文字列を既存の文脈付き要求セッションへ渡し、次turnの「それ」で処理結果を再利用する。自由文からの文書選択や標準チャットへの自動配線は追加しない。

## 7. 上限

原文262144 UTF-8バイト、JSON8192節点・深さ12、文字列32768文字、数値表記256文字・指数絶対値1000以下。CSVは総セル4096、64列、最大2049物理ではなく論理レコード、セル32768文字。操作列8件、型規則128件、行選択2048件、結果記録2000000バイト。超過で途中切断しない。

既存合成器のJSON契約・深さ上限も適用される。原文の再読と操作の再実行があるため、選択数だけに比例した高速性は保証しない。CPU・メモリの厳密な隔離、実トークナイザ、解析中の停止コールバックは今回追加しない。停止は既存合成器の呼出前後に従う。
