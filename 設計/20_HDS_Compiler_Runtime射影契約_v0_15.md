# HDS Compiler Runtime射影契約 v0.15

## 1. 目的

HDS Compilerの責務は、自然言語から得た情報を一つの平坦な語集合としてミニドラへ渡すことではない。

Compilerは完全なHDS-IRを保持し、そのIRからRuntime各主体・境界が実際に消費する最小十分なProjectionを渡す。

```text
自然言語
  ↓
HDS Compiler
  ↓
完全HDS-IR
  ├─ R核: 検索表層 / 検索述語 / 既知端点 / 条件
  ├─ K核: 意味語 / 関係種別 / 有向端点
  ├─ J核: 選択意図 / 値状態 / 残差 / 境界
  └─ M核: 完全IR / 由来 / 履歴 / 再開放情報
```

完全IRを削るのではなく、用途別に読む範囲を限定する。

## 2. 構造から逆算したK入力

現行K3/HDS native評価は主に次を消費する。

- 問いの意味語
- 候補の意味語
- 候補固有語
- 関係種別
- 始点→終点の有向関係
- 独立出典
- Fact confidence / 値状態 / 残差阻害

したがってKへ検索語、選択制御、監査要求、目的メタを混入させる理由はない。

Kへ渡すのは以下だけとする。

```text
対象 / 実体 / 状態 / 属性 / 値 / 条件 / 文脈上の意味
関係種別
関係の意味端点
残差と値状態
```

次はK世界事実へ入れない。

```text
検索.*
制御.*
目的.*
監査.*
保持.*
暫定性.*
帰還.*
原文保持 / language surface
```

## 3. 質問IRのK射影

### 3.1 未知スロット関係がある場合

例:

```text
Which molecule inhibits Enzyme X?
```

Compilerが既に

```text
未知始点 = molecule
関係 = 阻害
既知終点 = Enzyme X
```

を持つなら、Kへ必要なのは次だけである。

```text
関係種別 = 阻害
既知端点 = Enzyme X
未知位置 = 始点（端点は未観測のまま）
choice集合
```

重要なのは、未知なのは端点であって `阻害` という関係種別ではないことである。

従来は関係全体が `未観測` のためK側で関係種別まで落ちた。v0.15ではK質問射影上だけ関係種別を既知として扱う。

これは世界事実の確定ではなく、**問いが要求する作用素の確定**である。

### 3.2 関係質問でない場合

Compilerが `検索.英語正規化` を持つなら、その表層をK質問照合用の `対象.照合焦点` へ写す。

これは検索経路を証拠化することではない。単に「この問いは何についての問いか」という最小照合語として使う。

## 4. 候補IRのK射影

候補は他候補との差を識別するために使う。

したがって候補K射影は、

- 候補の意味対象
- 候補自身が明示する事実関係

だけを保持する。

検索語、目的、選択制御、監査情報は候補識別へ混ぜない。

## 5. Data IRのK射影

Rから取得したDataは世界証拠候補である。

Kへ投入してよいのは、

- 意味座標
- 明示関係
- 値状態
- 残差
- provenance / source confidence

である。

検索queryや「何を探したか」は世界事実ではないため、Data IRのK事実へ昇格させない。

検索経路を利用する場合は既存 `HDS参照検索経路` のように、低信頼・別由来の補助証拠として明示分離する。

## 6. J/M/Rとの非干渉

v0.15は元HDS-IRを変更しない。

- Rは元質問IRを使う
- Jは元質問IRと選択意図・残差・境界を見る
- Mは完全IRを保持する
- 直接関係検証は元質問IRと候補代入仮説を使う
- K3 baseline候補比較だけ用途別K射影を使う

従って圧縮による監査情報喪失は起こさない。

## 7. 不変条件

1. 完全HDS-IRを破壊しない。
2. Kへ検索・制御・目的・監査メタを世界事実として渡さない。
3. 未知端点と既知関係種別を同一の未観測状態へ潰さない。
4. K Data射影で片端しか残らない関係を生成しない。
5. R/J/Mの既存責務をKへ移さない。
6. benchmark固有分岐を入れない。
7. 世界知識を追加しない。

## 8. 検証順序

採否は次の順とする。

1. Runtime消費構造との整合
2. 単体回帰
3. Windows / Ubuntu CI
4. 既存機能非退行
5. 最後に外部benchmarkを受入確認として一度だけ実行

benchmark値を局所探索の勾配として使用しない。
