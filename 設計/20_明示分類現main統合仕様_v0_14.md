# 明示分類 現main統合仕様 v0.14

## 1. 目的

旧v0.3基準の独立測定で有効だった明示分類Projectionを、現在のmainにあるAND展開・共有言語基底P一般関係と共存させる。

旧独立測定では明示分類だけで次を記録した。

- correct: 29 / 198
- accuracy: 14.65%
- answered: 121
- answered accuracy: 23.97%
- SUSPEND: 77
- documents retrieved: 2689

この値は旧v0.3 base上の結果であり、現mainへの直接適用結果ではない。
従ってv0.14では、現mainへ分類だけを移植して再測定する。

## 2. 対象

- `A is a/an B`
- `A is a/an type of B`
- `A is a/an kind of B`
- `A is a/an form of B`
- `A is a/an class of B`
- `A is a/an example of B`

内部正本は `分類` とする。

## 3. 質問

```text
Which molecule is a compound?
```

を

```text
未知始点 = molecule
関係 = 分類
分類先 = compound
検索述語 = is a
```

へ落とす。

候補問題では未知始点へ候補を代入してR queryを生成する。

## 4. 現mainとの共存

処理順は次とする。

```text
英日意味射影
→ 一般関係射影
→ 明示分類射影
→ 明示AND展開
→ Front-End / HDS後段
```

分類はAND展開・一般関係Pを置換しない。

## 5. 安全境界

- `A is not a B` は肯定分類へしない
- `A is an inhibitor of B` 等の前置詞付き役割句を単純分類へしない
- 暗黙の世界分類を追加しない
- benchmark固有分岐を追加しない
- 既存一般関係Pを分類へ潰さない
- ORをANDとして扱わない

## 6. 採用条件

- 通常CI全通過
- AND展開・一般関係Pの回帰PASS
- 現mainのGPQA Diamond 198問と比較
- correct / answered accuracy / SUSPEND / documents retrievedを併記
- 明確な退行なら採用しない

旧v0.3上の29/198は有望性の根拠であり、現main採用の十分条件ではない。
