## 運用拘束

ルート[`AGENTS.md`](../AGENTS.md)の「HDS 大規模言語モデル運用拘束規約 v2.0」をLLM/Codexの最上位運用拘束として適用する。

通常のarchitecture分析、第一原理思考、根本原因分析、仮説検証法等をHDSとして代用しない。
