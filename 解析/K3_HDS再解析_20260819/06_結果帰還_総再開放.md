# 結果帰還と総再開放

## 0. 目的

前段で得た原理候補と局所適用結果を、最初の認知世界へ返す。

この文書は結論の固定ではなく、結果によって何を再開放する必要が生じたかを記録する。

---

## 1. 最初の認知世界へ返った変化

### 1.1 対象Projectionの再開放

開始時には、K3を次の複数Projectionとして保持した。

- 言語計算主体
- 学習済み能力体
- 大規模実装
- 運用系
- 訓練生成系

解析結果により、これらを一つの`K3 architecture`へ統合して扱うことは不適切であるという支持が強まった。

特に、K3 Technical Report自身がarchitectureだけでなく、training/data recipe、general/agentic/coding RL、reasoning effort、persistent rollout / sandbox stateを能力形成要因として併記するため、観測能力の因果帰属をarchitecture単独へ閉じない。

### 1.2 因果Projectionの再開放

旧い暗黙モデル:

```text
K3 architecture
→ K3能力
```

は棄却せず、支持不足モデルへ降格する。

現時点では、

```text
architecture
training data
training objective
post-training
RL
reasoning policy
外部環境 / tool / rollout state
        ↓ 相互作用 ?
観測されるK3能力
```

という複合生成モデルを優先するが、寄与率は未観測のため固定しない。

### 1.3 weightに対する対象化の再開放

`2.8T scalarの個別意味復元`を再構成の必要条件とする対象化は撤回する。

weightは、少なくとも学習結果を保持する実装媒体として観測される。しかし、

```text
個々のscalar意味が一意に読めない
→ 非ニューラル再構成不能
```

は成立していない。

再構成で必要なのは、観測能力を成立させる作用構造をどこまで実行可能形式へ再表現できるかであり、scalar同型復元を最初から要求しない。

ただし、weight内部に保持されたCapability / Knowledge / Relation / Transformationをどこまで分離できるかは未解のまま残す。

## 2. Layer-0への帰還

現行`設計/02_Layer0責任契約.md`に対し、次を再監査対象へ戻す。

### 2.1 維持支持が強い責任

- 状態保持
- 内容依存参照
- 条件付き変換
- 関係合成
- 結果形成

これらはK3固有機構を除去しても、異architecture比較で機能同値作用が残る方向にある。

### 2.2 再開放する責任

#### 直列深度

物理layer数や特定residual経路を意味しないよう、責任名と定義を再監査する。

より根本側では、

```text
中間状態を保持しながら、必要な変換を反復・継続できること
```

が対象である可能性が高い。

候補名称:
- 反復変換
- 多段継続
- 状態反復

名称はまだ確定しない。

#### 停止

以下を分離する。

```text
計算主体の終了条件
```

と

```text
HDS判断主体による採否・保留・拒否
```

現行契約の`未解、矛盾、境界違反等に応じて処理を停止する`は、LLM計算核とHDS判断責任が混在している可能性がある。

よって再開放する。

## 4. 外部参照Rへの帰還

MINIDORAの設計仮説:

```text
Capability → P
Knowledge/Data → R
```

は維持するが、K3 HDS解析から発見済み原理へ昇格しない。

結果帰還により必要となった検証は次。

1. 同一問題Dataを外部Rへ置いても推論Capabilityが維持されるか。
2. Pへ残すべきKnowledge-like structureと、Rへ分離可能なDataの境界はどこか。
3. 参照失敗・遅延・誤検索でCapabilityがどのように崩れるか。
4. Knowledgeをweight内部に持つK3と、外部Rへ置くMINIDORAを同一harnessで比較した時、何が差として残るか。

この検証がない限り、`Knowledge外部化 = K3同等`と主張しない。

## 5. 日本語基底への帰還

日本語基底はK3から発見した原理ではなく、MINIDORAの内部表現設計仮説である。

本Runの結果は、英語技術語を後から翻訳する方式を否定する設計方針と整合する。

今後の解析・命令構文化では、

```text
原資料の意味保持
→ 日本語で認知世界形成
→ 日本語で原理質問
→ 日本語で原理分別
→ 日本語で命令構文化
```

を維持する。

情報工学上の効率優位は未実測なので、次を測る。

- 同一命令意味に必要な記号数
- 参照索引の照合量
- 命令列長
- 監査履歴長
- 同一意味を保持した時の圧縮率
- 曖昧性保持と誤解釈率

## 6. 選択的情報流への帰還

K3では、時間・文脈・深度・幅・計算予算の複数軸で選択が反復する。

これはK3の特徴的な性能構造として保持するが、Layer-0普遍責任へは昇格させない。

現時点の状態:

```text
選択的情報流
= frontier規模における性能/効率の局所原理候補
≠ LLM成立の普遍必要条件
```

DeepSeek / Qwen / Llama / MiniMaxとの追加比較、摂動、同一harness評価で再開放する。

## 7. 次の外部接触

原理候補をさらに閉じるために必要なprobe:

1. Kimi LinearのKDA vs full MLA比較を、状態作用の観点で再記述する。
2. Attention Residuals ablationを、深度選択が何を変えたかで再監査する。
3. Dense LlamaとMoE K3/DeepSeek/Qwen/MiniMaxを同一能力軸で比較する。
4. reasoning effort差から、計算量増加と能力変化の対応を見る。
5. fixed Knowledge条件で、P/R分離実装のheld-out性能を測る。
6. long-contextで、保持・忘却・再参照のどの作用が必要かを見る。
7. agentic benchmarkでmodel core / tool / environment / rollout stateの責任を分別する。

## 8. 現時点の局所閉包状態

### 局所的に運用へ使える

- KDA / MoE / AttnResをLayer-0へ直接持ち込まない。
- scalar個別意味復元を再構成の前提にしない。
- 文脈状態継続、条件付き変換、反復合成をLayer-0/P候補として扱う。
- K3能力をarchitecture単独へ帰属しない。

### 保留

- Capability / Knowledgeの完全分離可能性
- 外部RでK3同等Knowledge能力を再構成できるか
- 選択的情報流の普遍原理性
- 1M contextの最小原理
- multimodal入力が言語核へ与える構造変化
- agentic能力のmodel core寄与境界
