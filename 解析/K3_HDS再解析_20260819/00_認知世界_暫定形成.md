## 1. 現時点の対象化

今回の対象を、最初から「K3の重み」「K3のarchitecture」「K3という製品」のどれか一つへ固定しない。

並列に次の対象Projectionを保持する。

1. **K3言語計算主体**: 入力を受け、文脈依存で変換し、言語結果を形成する部分。
2. **K3学習済み能力体**: 学習によって獲得された変換傾向・知識・技能が混成した状態。
3. **K3大規模実装**: KDA、Gated MLA、Attention Residuals、Stable LatentMoE等を含む物理・数値実装。
4. **K3運用系**: reasoning effort、tool使用、sandbox、agentic rollout等を含むモデル外またはモデル周辺の運用構造。
5. **K3訓練生成系**: pre-training、data recipe、SFT、RL、agentic/coding RL等、能力を形成した履歴系。

これらは同一物とは扱わない。後続観測により統合・分裂・境界変更を許容する。

## 2. 観測者Projection

観測者は、公開一次資料へ接触可能なLLM実行主体である。

観測可能:
- Moonshot AI公式Kimi-K3 repository
- Kimi K3 Technical Report / arXiv
- Kimi Linear論文
- Attention Residuals論文
- 公式model card /公開configに現れる範囲
- 比較用の公開一次資料

観測不能または未観測:
- K3全training dataの完全内容
- 全2.8T scalarと個別意味の一対一対応
- 非公開training log全量
- 全内部activationの網羅的観測
- 本Run時点で実行していないK3 I/O probe
- 非公開評価harnessの内部状態

観測不能を一般論で補完しない。

## 4. 目的・価値・リスク

### 目的
K3の部品表を作ることではなく、「何がK3の観測能力を成立させているのか」を原理層まで分別する。

### 価値
- K3固有構造を除いても残る作用を抽出する。
- Layer-0へ縮約可能な責任と、性能向上用の実装分岐を分離する。
- CapabilityとKnowledge/Dataを混線させない。
- 非ニューラル実装へ移す際に、K3の物理構造を模倣する必要があるかを監査する。

### 主な誤投影リスク
- KDAがある → KDAがLLM原理、と誤る。
- MoEが高性能 → MoEがLLM原理、と誤る。
- 2.8T weightがある → 個々のscalar意味復元が再構成の必要条件、と誤る。
- benchmarkが高い → architecture単独が原因、と誤る。
- agentic性能が高い → model core単独能力、と誤る。
- 外部参照設計を採用したい → K3から外部Knowledge分離原理が導出された、と逆投影する。
