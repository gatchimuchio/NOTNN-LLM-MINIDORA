## 1. K3直接観測

### O-K3-01 規模
観測:
- 総parameter約2.8T
- activated parameter 104B
- 93 layers

解釈禁止:
- parameter数そのものを能力原理と断定しない。
- scalar個別意味復元を非ニューラル再構成の必要条件としない。

### O-K3-02 注意・状態経路
観測:
- 69 KDA + 24 Gated MLA
- KDAはKimi LinearでGated DeltaNetを拡張し、有限状態memoryの利用改善を狙うものとして公開されている。
- Kimi Linearは同一training recipeの比較でfull MLAより高性能かつKV cache削減・1M context decoding高速化を報告している。

解釈禁止:
- KDAがLLM成立の必要条件とは読まない。
- full attentionが成立している事実を捨てない。

### O-K3-03 深度経路
観測:
- K3はAttention Residualsを採用。
- AttnRes論文は、通常residualの固定加算を、入力依存で過去depth表現を選択・集約する方式へ置換している。
- 論文自身がstandard residualを既存基準として扱い、AttnResをdrop-in replacementとして評価している。

解釈禁止:
- AttnResをLLM原理と直結しない。
- 深度方向の内容依存選択が性能改善要因であることと、LLM成立必要条件であることを混同しない。

### O-K3-04 幅・専門器
観測:
- Stable LatentMoE
- routed experts 896
- tokenごとに16を活性
- shared experts 2

解釈禁止:
- MoEをLLM成立原理としない。
- expert数やTop-k値をLayer-0へ持ち込まない。

### O-K3-05 長文脈・multimodal
観測:
- context length 1,048,576
- native vision
- MoonViT-V2 vision encoder

解釈禁止:
- 1M contextの成立原因をKDA単独へ帰属しない。
- vision入力が言語計算核を変更するかは未分別。

### O-K3-06 training / post-training / agentic
観測:
K3 technical reportは、architectureだけでなく、refined training/data recipes、general/agentic/coding RL、multiple reasoning-effort levels、persistent rollout / sandbox states等を性能要因として併記している。

解釈禁止:
- K3のagentic・coding性能をarchitecture単独成果としない。
- model coreと外部運用系を同一視しない。

## 2. 近縁系からの観測

### O-KL-01 Kimi Linear
Kimi Linearは、KDA + MLA hybridで48B total / 3B activeのモデルを構成し、full attention/MLAとの比較を公開している。

意味:
- KDAは少なくとも「唯一のLLM成立形」ではない。
- KDAの観測価値は、有限状態memoryをどう使うかという作用差にある可能性が高い。

### O-AR-01 Attention Residuals
AttnResは、depth方向の固定加算を内容依存選択へ変えることで性能改善を示す。

意味:
- 「深度のどこを再利用するか」という選択軸は性能原理候補。
- ただしstandard residualでもLLMは成立するため、LLM存在必要条件とは未確定。

## 3. 異系統比較観測

### O-LLAMA-01 Dense
Llama 3.1最大系はdense Transformerとして成立し、高い言語・coding・reasoning能力を報告している。

意味:
- sparse MoEはLLM成立の必要条件ではない。
- MoEからLayer-0へ残せるとしても「条件付き変換」「能力選択」等の実装非依存作用まで引き上げる必要がある。

### O-DS-01 DeepSeek-V3
DeepSeek-V3はMLA + DeepSeekMoEを用い、671B total / 37B active、multi-token prediction、14.8T token pretraining等を公開している。

意味:
- K3と同じMoE系でもattention/state、routing、training objectiveは異なる。
- 高性能に共通するものをK3固有mechanism名へ還元できない。

### O-QWEN-01 Qwen3.5/3.8
Qwen3.8はQwen3.5 architecture foundation上にあり、公式repositoryはQwen3.5をGated Delta Networks + sparse MoEのhybrid architectureとして説明する。Qwen3.8ではreasoning effortとthinking context保持も公開されている。

意味:
- recurrent/delta系の状態機構はKDA固有ではない。
- reasoning depthの可変化はK3固有でもない。

### O-MM-01 MiniMax-M2
MiniMax-M2 seriesはMoEでありながらactive parameterを小さくし、agentic training pipeline、agent-native RL system、training-inference-agent decoupling等を性能要因として公開する。

意味:
- agentic性能はmodel architectureだけでなくdata / RL / environment / scaffoldとの複合成果である可能性を保持すべき。

## 4. 未観測・未説明残差

- K3 training corpusの完全な内容と寄与分解
- 各能力に対するarchitecture / data / training / post-training寄与率
- K3全内部activationの因果介入
- reasoning effort各段階の同一prompt全数比較
- K3からKnowledgeだけを外部化した場合の能力保持率
- vision入力を除いた場合の言語能力変化
- 1M context内で何を保持・何を忘却・何を再参照しているかの網羅的観測
- agentic benchmarkでmodel coreとharnessが担う責任の完全分離

これらを未観測のまま一般論で埋めない。
