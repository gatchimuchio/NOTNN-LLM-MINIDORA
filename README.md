内部命令・状態・採否・履歴・台帳は、可能な限り漢字中心の日本語を正本とする。本プロジェクトでは、英語の長い表音記述より短い表意記号を用いることで、命令保持・検索・比較・監査の情報密度向上を狙う。これは工学的な設計仮説であり、普遍的優位を証明済みとは扱わない。

英字はPython構文、HTTP／JSON／SHA-256／safetensors、K3公式tensor名・config key・shard名、URL、commit SHA、license、外部互換APIに限定する。
