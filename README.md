## 重要境界

- K3は再実装すべきarchitectureではなく教師データである。
- HDSはGateやラベルではなく、教師データから意味系を分別する方法論である。
- KDA / MoE / Attention / Transformer等は教師側観測であり、実行Pの正本語彙へ残さない。
- scalarを一個ずつ意味へ対応付けることを目的にしない。
- 日本語は外部入出力制限ではなく、内部意味系・解析・命令構文の基底言語である。
- 外部言語・視覚等はAdapter責任として内部日本語意味へ接続する。
- training / RL / distillationはP形成側へ、GPU / quantization / cache等は実装効率側へ分離する。
- benchmark値は能力の教師証拠であり、命令そのものではない。
