# NOTNN-LLM-MINIDORA

## 非ニューラルLLM「ミニドラ」

MINIDORAは、巨大ニューラルネットワークやTransformerを実行基盤とせず、LLM機能を通常計算機上の分離構造として実装する非ニューラルLLMである。

Kimi K3の公開情報と外部挙動を参照点として、実装固有物ではなく能力・責任・処理構造を抽出し、MINIDORA側の実行構造へ再構成している。上流の内部解析方法そのものは本リポジトリの公開対象に含めない。

## 基本構成

```text
外部Data
  ↓
参照層 R
  ↓
Layer-0 × 命令形P
  ↓
採否・結果形成
  ↓
Output
```

- **Layer-0**: 状態保持、参照、条件付き変換、関係合成、逐次計算、結果形成、停止を担う最小実行核
- **P**: Layer-0が実行できる能力・作用・境界・停止条件を保持する命令形
- **R**: Data / Knowledgeを供給する交換可能な外部参照層
- **Runtime**: P・R・Layer-0を接続し、計算結果と採否を返す

純粋計算主体は次で表す。

```text
C = L0 ⊗ P
```

DataはRとして計算主体から分離する。
