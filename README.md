# NOTNN-LLM-MINIDORA

## 非ニューラルLLM「ミニドラ」

このリポジトリは、Kimi K3をHDSで解析し、実装固有構造をLayer-0へ縮約し、日本語命令形Pと外部参照Data Rへ再構成することで、非ニューラルLLMを実装・検証するための正本である。

## HDS運用拘束

LLM / Codexによる解析・実装は、ルート[`AGENTS.md`](AGENTS.md)の**HDS 大規模言語モデル運用拘束規約 v2.0**に従う。

HDS正本と競合する場合はHDS正本を優先する。

HDSを、既存方法論へ翻訳・置換した通常分析、第一原理思考、根本原因分析、仮説検証法、チェックリスト処理として実行してはならない。

必須遷移:

```text
認知世界の暫定形成
→ 原理質問
→ 開放並列場
→ 原理の分別
→ 局所適用
→ 結果帰還
→ 総再開放
```

## 重要境界

- KDA / MoE / Attention / Transformer等は入力側の観測資料であり、Layer-0の正本語彙ではない。
- scalarを一個ずつ意味へ対応付けることを目的にしない。
- Capabilityは命令形Pへ、Knowledge/Dataは外部参照Rへ分離する。ただしこの分離によるK3同等性は設計仮説であり、HDS解析済み原理として扱わない。
- 外部参照RはRAG追加機能ではなく標準Data Layerである。
- 日本語は表示言語ではなく、HDS解析・原理化・Layer-0縮約・命令実行の基底言語である。
- HDS採否GateとHDS解析本体を混同しない。

## 実装順序

1. K3公開情報を観測台帳へ固定
2. HDSの認知世界を暫定形成
3. 原理質問を立てる
4. 開放並列場で別対象化・別Model・反対Model・不可能性・未観測・残差を保持する
5. 観測/パターン/Model/Mechanism/原理を分別する
6. 原理候補を現在条件へ局所適用する
7. 結果を上流へ帰還し総再開放する
8. 局所的に許可された責任だけをLayer-0へ射影する
9. 日本語命令形Pへ構文化する
10. 外部参照Rと接続する
11. Runtime実装・held-out / 摂動 / 反実仮想 / 同一harness評価を行う
12. 結果を再びHDS Runへ帰還する

HDS適合条件が成立する前に、K3固有mechanismを直接コードへ写像しない。
