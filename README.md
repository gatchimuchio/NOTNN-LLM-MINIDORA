# ミニドラ（MINIDORA）

**NOTNN-LLM-MINIDORA** は、巨大ニューラルネットワークや Transformer を実行基盤とせず、LLM 的機能を通常計算機上の分離構造として実装する非ニューラルネットワーク LLM の研究・実装リポジトリです。

- 基底言語: **日本語**
- 正本ブランチ: **`main`**
- ライセンス: **Apache License 2.0**
- 著作: **がっちむち♂**
- 実装言語: Python 3.11+

## 目的

MINIDORA は、LLM を Transformer やニューラルネットワークという特定実装と同一視せず、必要な能力・責任・処理構造へ分離し、通常計算機上で再構成することを目的とします。

Kimi K3 の公開情報と外部挙動を参照点として、実装固有物ではなく能力・責任・処理構造を抽出し、MINIDORA 側の実行構造へ再構成しています。上流の内部解析方法そのものは本リポジトリの公開対象に含めません。

## 基本構造

```text
外部 Data
  ↓
参照層 R
  ↓
Layer-0 × 命令形 P
  ↓
採否・結果形成
  ↓
Output
```

純粋計算主体は次で表します。

```text
C = L0 ⊗ P
```

Data / Knowledge は `R` として計算主体から分離します。

### 構成要素

- **Layer-0**: 状態保持、参照、条件付き変換、関係合成、逐次計算、結果形成、停止を担う最小実行核
- **P**: Layer-0 が実行できる能力・作用・境界・停止条件を保持する命令形
- **R**: Data / Knowledge を供給する交換可能な外部参照層
- **Runtime**: P・R・Layer-0 を接続し、計算結果と採否を返す実行層

## 実行と試験

Python 3.11 以上を使用します。

```bash
python -m venv .venv
python -m pip install -e .
python -m unittest discover -s tests -v
```

仮想環境の有効化方法は OS / shell に応じて選択してください。
