# 結論と主張境界

## 1. 結論

K3の公開情報から、次の処理責任は明示命令へ変換できた。

```text
時間軸       KDA
→ RETAIN / ERASE / DELTA_WRITE / READ

文脈軸       Gated MLA
→ SELECT_REFERENCE / LATENT_COMPRESS / GLOBAL_RECONCILE / OUTPUT_GATE

深さ軸       Attention Residuals
→ STAGE_REGISTER / DEPTH_SCORE / DEPTH_TOPK_READ / BLOCK_ACCUMULATE

幅軸         Stable LatentMoE
→ ROUTE / TOP16 / SHARED2 / LATENT_COMPRESS / EXPERT_EXECUTE / RECONCILE

計算予算軸   multiple effort policies
→ SET_BUDGET / STOP_ON_CLOSURE / ESCALATE

外部data軸
→ QUERY_PROVIDER / LOAD_REFERENCE / BIND_PROVENANCE / VERIFY
```

これにより、ニューラルframeworkを使わない決定的な言語処理Runtimeは成立した。

## 3. 「重みを命令に変換する」の三段階

### 3.1 Architecture-role conversion

```text
KDA tensor family
→ 時間状態の保持・消去・書込み命令
```

これは公開code・configから直接支えられる。実装済み。

### 3.2 Tensor-role conversion

```text
model.layers.3.self_attn.a_log
→ KDA_RETENTION_CONTROL
```

checkpoint index／headerを読み、tensorごとの処理責任へ変換する。実装済み。ただし全96 shardは本成果物環境では処理していない。

### 3.3 Scalar-semantic conversion

```text
個々の4bit/8bit scalar
→ どの概念、知識、規則、表現を保持しているか
```

これはtensor名とshapeだけからは一意に決まらない。完全training dataも非公開である。よって未成立を隠さない。

## 4. K3同等と呼べるための必要Gate

1. 全checkpoint tensor roleの100%解決
2. scalar semantic extractionの再現可能性
3. K3と同一prompt・同一dataset・同一採点器で能力比較
4. open-domain knowledge
5. 1M context
6. multimodal
7. long-horizon coding／agentic execution
8. cost／latency／memory
9. perturbation／ablation
10. blind evaluator

現時点ではこのGateを通過していないため、K3同等宣言は行わない。
