# 非ニューラルK3アーキテクチャ

## 全体

```text
要求
  ↓
参照経路器
  ├─ 固定資料
  ├─ 検索API
  ├─ DB
  ├─ 文書庫
  └─ 任意LLM API（単なるProvider）
  ↓
参照記録
  ↓
命令変換器
  ↓
手順
  ↓
記号KDA状態
  ↓
疎専門経路
  ↓
手順実行器
  ↓
注意残差段階庫
  ↓
全体照合
  ↓
独立再実行検証
  ↓
HDS由来採否
  ↓
結果
```

外部参照層は標準構成であり、OFFはablationである。

## 時間軸

Native K3は69 KDA＋24 Gated MLA。射影版では、KDAを保持／消去／差分書込／読出の明示状態へ、Gated MLAを参照選択／全体照合／出力門へ変換する。

## 深度軸

Native K3のBlock Attention Residualsは過去深度を内容依存で再利用する。射影版ではframe、reference、program、execution、verificationを段階庫へ登録し、query tagとの関係で再読込する。これは処理責任の射影であり、学習済みpseudo-queryの完全再現ではない。

## 幅軸

Native K3は896 routed expertsから16、shared 2。射影版は896 descriptorを保持し、問題系統とfeatureから決定的に上位16を選ぶ。共有言語・共有採否を常時適用する。expertの学習済み能力内容は明示operatorと外部referenceへ置換する。

## 計算量軸

```text
低    最小参照・最小段階・早期停止
高    追加参照・追加検証
最大  最大段階再利用・独立再実行
```

## Data軸

```text
K3
Data → Training → Weights → Inference

ミニドラK3命令化版
Data → Reference Provider → Program → Executor
```

検索API、固定corpus、DB、文書collectionは同じProvider interfaceへ接続できる。LLM APIは任意であり必須ではない。

## 採否軸

公開版はHDS本体ではなく局所採否Projection。

```text
証拠
矛盾
検証
危険
権限
```

候補生成系は自己commitしない。

## Multimodal軸

Vision tensor role mappingとinterfaceは実装した。画像patch化、視覚関係抽出、language stateへの意味変換は未実装。K3 vision同等は未成立。
