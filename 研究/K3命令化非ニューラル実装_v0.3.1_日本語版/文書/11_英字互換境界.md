# 英字互換境界

```text
内部命令・台帳・履歴 = 日本語正本
外部標準・公式番地   = 英字保持
互換API              = 薄い別名
```

## 日本語API

```python
from minidora_k3 import ミニドラK3, 計算量

実行系 = ミニドラK3.内蔵参照から構築()
結果 = 実行系.実行("K3の共有専門家数は？", 計算量=計算量.最大)
```

## 英字互換

```python
from minidora_k3 import K3NotNN, Effort

runtime = K3NotNN.from_builtin_reference()
result = runtime.run("K3の共有専門家数は？", effort=Effort.MAX)
```

英字互換は外部接続・移行用であり、新規内部実装では日本語APIを正本とする。

## 英字を保持する理由

- Python構文と標準ライブラリの互換性
- HTTP／JSON／SHA-256／safetensors等の標準仕様
- K3公式tensor名・config key・shard名から公開weightへ再接続するため
- URL、commit SHA、license、第三者API fieldを原文の番地として保持するため

翻訳で番地を壊さず、日本語の役割命令を別層に結合する。
