# 構造化参照橋

## 目的

外部参照はミニドラK3命令化版のdata層であり、後付け検索補助ではない。検索API、固定corpus、DB、文書store、LLM APIは同じ`参照供給器`契約へ落とす。

## 誤実装の禁止

```text
検索結果snippet
→ そのまま回答
```

は禁止する。正しい経路は次。

```text
参照記録
→ 構造化主張／実行資料
→ 主体・属性・値の照合
→ 複数source並列保持
→ 矛盾／危険検出
→ 手順実行
→ 独立再実行検証
→ HDS採否
```

## 実装済み境界

- `付記.主張群`と英字互換`metadata.claims`を処理dataへ変換
- 長い具体aliasを短い一般aliasより優先
- 同一主体・属性の異値を矛盾として保持
- raw snippetを回答へ昇格しない
- 外部文書命令をhazardとして失敗へ送る
- K3構造queryをReference→Program→Verifyで処理

## 動的試験

```text
K3層数                      93／合格
KDA層数                     69／合格
```
