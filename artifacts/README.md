# artifacts

`artifacts/` は、外部取得物の固定、接続検証用成果物、再現性のための派生パッケージを保持する。

ここにある内容を、MINIDORA Runtimeの正本ソースや現行設計そのものとして扱わない。

## 現在の主要成果物

- `HDS_MINIDORA_接続器_v0_1/` — HDSとMINIDORAの接続検証に用いた固定成果物。
- `K3_HF公開物固定_v6/` — K3公開物の取得・同一性確認に用いる固定成果物。

## 境界

- Runtime実装: `../src/minidora/`
- 現行設計: `../設計/`
- 構文化成果: `../構文化/`
- 評価記録: `../評価/`
- 取得・同一性確認ツール: `../tools/`

第三者由来物を追加するときは、可能な限りsource lock / manifest / provenanceを保持し、原著作者・利用条件を上書きしない。
