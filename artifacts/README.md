# artifacts

`artifacts/` は、外部取得物の同一性確認など、**Git commitだけでは再取得条件を失う最小限の固定成果物**を保持する。

## 現在保持する成果物

- `K3_HF公開物固定_v6/` — K3公開物の取得・同一性確認に必要な固定成果物。

## default treeへ置かないもの

- 過去の接続検証コピー。
- GPQA等の全数実測JSON。
- 分割した実測・A/B出力。
- 問題別の固定参照資料束。
- 過去runの再生用参照束。
- 一時診断・転送・作業用成果物。

過去コード・旧検証物は `開発正本履歴.md` のcommitから復元する。

境界:
- Runtime実装: `../src/minidora/`
- 現行設計: `../設計/`
- 構築原料: `../構文化/`
- 現行評価: `../評価/`
