# artifacts

`artifacts/` は、外部取得物の同一性確認や接続検証に必要な**小さな固定成果物だけ**を保持する。

ここにある内容を、MINIDORA Runtimeの正本ソースや現行設計そのものとして扱わない。

## 現在保持する成果物

- `HDS_MINIDORA_接続器_v0_1/` — HDSとMINIDORAの接続検証に用いた固定成果物。
- `K3_HF公開物固定_v6/` — K3公開物の取得・同一性確認に用いる固定成果物。

## default treeへ置かないもの

次はリポジトリ本体へ固定せず、必要ならGitHub Actions artifactまたは`評価/`の要約記録として保持する。

- GPQA等の全数実測JSON。
- 分割した実測・A/B出力。
- 問題別の固定参照資料束。
- 過去runの再生用参照束。
- 一時診断・転送・作業用成果物。

現行GPQA正本はLIVE_ONLYであり、固定参照資料を性能評価入力へ再利用しない。

## 境界

- Runtime実装: `../src/minidora/`
- 現行設計: `../設計/`
- 構文化成果: `../構文化/`
- 評価記録: `../評価/`
- 取得・同一性確認ツール: `../tools/`

第三者由来物を追加するときは、必要最小限のsource lock / manifest / provenanceだけを保持し、原著作者・利用条件を上書きしない。
