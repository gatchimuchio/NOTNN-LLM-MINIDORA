# 教師固定

`K3公開意味教師データ`は197件を、GitHub上では25件単位のJSONLへ分割して保存する。

数値順に連結すれば正本の197件を復元できる。

```text
教師_0001_0025.jsonl
教師_0026_0050.jsonl
教師_0051_0075.jsonl
教師_0076_0100.jsonl
教師_0101_0125.jsonl
教師_0126_0150.jsonl
教師_0151_0175.jsonl
教師_0176_0197.jsonl
```

各行は最低限、`教師観測 / 出典 / HDS意味分別 / 写像先 / 日本語構文 / 未解残差 / HDS再開放条件`を保持する。

この教師台帳自体が全件写像台帳を兼ねる。
