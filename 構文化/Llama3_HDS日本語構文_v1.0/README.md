# Llama3_HDS日本語構文_v1.0

Meta Llama 3（2024-04-18公開 8B/70B、Pretrained/Instruct）の公開情報を、
HDS 大規模言語モデル運用拘束規約 v2.0 に従って日本語基底で構文化した固定物。

## ここで行ったこと

- 一次公式記事・Model Card・評価条件・公式参照実装を確認
- 後発 `The Llama 3 Herd of Models` を時点分離した系列証拠として確認
- 公開観測を 225 件の教師recordへ分解
- 各recordで観測 / 意味分別 / 成立関係 / 反対保持 / 残差 / 再開放条件を保持
- 全体の成立関係群を別ファイルに固定
- HDS五条件を監査

## ここでは行っていないこと

- Layer-0化
- P / 命令形抽出
- Adapter化
- 最小構成化
- ミニドラ実装への変換
- K3との比較・統合
