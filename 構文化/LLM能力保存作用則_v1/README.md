# LLM能力保存作用則 v1

- 日付: 2026-08-26
- 基底言語: 日本語
- ライセンス: CC-BY-4.0
- 対象: K3 D4観測 + K3を除く10モデル第二巡構文化
- 目的: 実LLMで観測した能力成立作用を、MINIDORAへ部品名ではなく作用則として射影する

## 1. 境界

本正本は、KDA / MLA / Attention / MoE / Transformer等の物理部品をMINIDORAへコピーしない。

観測から直接保持するのは次の作用差である。

1. 中間状態を一回の採否で捨てない。
2. 同じ意味差へ複数段から再作用できる。
3. Gateは途中状態の真偽確定ではなく寄与調整として利用できる。
4. 過去段階の状態差を後段から再参照できる。
5. 共通作用と条件付き専門作用を再結合できる。
6. 候補差は終端まで共存させ、一意な成立差が形成されてから外へ出す。
7. runtime作用機構と形成済み関係を分離する。

## 2. 非ニューラル射影

MINIDORAでは連続activationやlearned weightを模写せず、次へ射影する。

```text
意味保存済み入力状態
↓
状態分離
↓
参照状態ごとの符号付き寄与
↓
候補共同差
↓
累積状態を保持した再結合
↓
終端でのみ一意差を確定
```

### 状態同一性

表層文字列完全一致を要求しない。

- 既知一般関係族: 関係種別 + 端点意味 + 方向 + 極性 + scope
- 開放述語: 述語意味 + 端点意味 + 方向 + 極性 + scope
- 記号・数式anchor: 異なる明示記号を無言同一視しない

### 寄与Gate

Gateは `通す / 捨てる` の二値にしない。

- 同方向・同極性・同scope: 強支持
- 同方向・反対極性: 反証
- 逆向: 弱い反証
- scope差: 弱い符号付き寄与
- 無関係: 0

数値はK3 weight値の再現値ではなく、観測された作用順序を保つ**序数射影**である。

### checkpoint

MINIDORA模型核は各能力作用段の候補差をcheckpointとして保持する。
過去差を破棄して後から救済するのではなく、累積寄与台帳を保持することで、過去作用への再アクセス可能性を決定論的に実現する。

## 3. 形成則の境界

K3のraw training trajectoryやweight内部方向ごとの自然言語意味は未観測である。
従って、形成済みweightの具体的数値を推測してMINIDORAへ埋め込まない。

本v1で固定するのは、

- runtime作用則
- 意味同一性
- 寄与の符号順序
- 状態保持と再結合
- 形成済み関係とruntime機構を混同しない境界

までとする。

世界知識は外部Data / Kとして別責務に保ち、能力作用則へ百科事典的事実を埋め込まない。

## 4. 実装正本

- `src/minidora/能力作用則.py`
- `src/minidora/模型.py`
- `src/minidora/hds_model_projection.py`

HDS型は模型核へ入れない。`hds_model_projection.py` が意味保存済みHDS-IRを汎用言語状態へ変換する外部Adapterである。

## 5. 禁止

- GPQA正解ラベルの利用
- benchmark固有語の能力規則への埋め込み
- K3 weight値の推測コピー
- 同一表層文字列だけを意味同一性とすること
- 未確定関係の即時廃棄
- 外部Dataを会話履歴へ混入すること
- K3 helperを正式MINIDORA模型核の代わりに最終回答主体とすること
