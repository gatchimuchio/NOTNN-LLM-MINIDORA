# Llama 3 自己一貫性 ↔ K3 差分

## 前提

- **基盤**: K3
- **対抗基準**: Llama 3
- **目的**: K3へLlama3型の自己一貫性を内包する
- 他LLMはこの二者の差分を精密化する補助観測点

## 構造差分

| 軸 | Llama 3 | K3 | 自己一貫性への意味候補 |
|---|---|---|---|
| 主体住所 | system/user/assistantを系列化 | role等を系列化 | 共通。差分ではない |
| 過去自己 | 過去assistant全文が文脈内で再入力 | KDA state + MLA文脈 | Llamaは文脈内では直接住所が強い |
| 系列方向 | 全層global causal attention | KDA + MLAの非同型補完 | K3は履歴表現が複合 |
| 深さ方向 | 直前状態への逐次Residual | AttnResで先行blockを選択参照 | Llamaは一本の深さ主幹 |
| 幅方向 | Dense FFN、routerなし | LatentMoE expert routing + shared path | Llamaは全token共通変換経路 |
| 選択形成 | SFT/RS/PPO/DPOで同一modelの選択傾向を形成 | specialized RL experts → MOPD統合等 | K3は形成経路が複合 |
| runtime自己状態 | 専用永続stateなし | KDA recurrent state等はあるが「自己専用」ではない | ミニドラでは明示state化できる |
| 更新 | 文脈再入力で毎turn再構成 | recurrent/attention/MoEで複合更新 | 明示的主体主幹を追加する余地 |

## 最重要差分

### 1. Llama 3は「共通経路」が強い

Llama 3では、各tokenが全層を通過し、各層のDense FFNを必ず通る。
内容によってexpertへ分岐するrouterはない。
これは「何を処理していても、同じ変換主体を通る」という構造的同一性を与える。

### 2. K3は「動的専門化」が強い

K3は系列・深さ・幅の三方向で別の選択機構を持つ。

- 系列: KDA / MLA
- 深さ: AttnRes
- 幅: LatentMoE

これは能力・効率には有利でも、「全処理が同じ主体主幹を通る」という条件はLlama3より弱くなる可能性がある。

ただしK3にはshared full-width pathがある。
従って、Llama3のDense全部を移植する必要はなく、**K3のshared pathを主体主幹として強化する**方がK3基盤を壊さない。

## HDS機構候補

> K3の専門経路は能力作用として残し、主体同一性に関わる状態だけはroutingの外側に置く。

専門家は「考える」。
主体主幹は「誰として判断するか」を保持する。

この分離がLlama3の一貫性をK3へ内包する最短候補である。
