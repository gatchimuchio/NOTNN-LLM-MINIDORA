# 旧 Llama3 HDS v1.0 → 自己一貫性再構文化 v2 差分

## 結論

旧v1.0は15の成立関係を横並びで保持していた。今回v2では、そのうち自己一貫性に関与する関係を**時間方向の一つの循環**として再接続した。

### 旧v1.0で既にあったもの

- REL-03 会話役割の系列内符号化
- REL-04 自己回帰状態遷移
- REL-05 参照配分
- REL-06 状態保持と推論効率
- REL-07 層内差分累積
- REL-10 後学習による出力選択傾向形成
- REL-11 生成可能性と選択の分離
- REL-12 デコード規則による実行時分岐
- REL-15 公開境界

## 今回の再解釈

### D1: REL-03 + REL-04 を「主体住所の時間連続」へ接続
旧版では会話形式と自己回帰を別機構として保持していた。
今回は、assistantという生成住所がturnごとに再設定され、前turnのassistant出力が次turnの条件へ戻ることで、主体が時間方向へ再構成される関係として接続した。

### D2: REL-07 を単なるResidual計算から「深さ方向の同一主幹」候補へ昇格
旧版では `x + Attention -> h + FFN` を状態更新として記述した。
今回、K3 AttnResとの相対化により、「直前状態へ逐次差分を積む」こと自体がLlama3側の一様性として見えるようになった。

### D3: Dense FFNの意味が相対化で初めて立った
Llama3単独ではDense FFNは「普通の実装」に見える。
K3 LatentMoEと並べると、**token依存routerなしで全tokenが同じ各層経路を通る**ことが独立差分として浮上した。
これを自己一貫性の原因と断定はしないが、主要機構候補へ昇格する。

### D4: REL-10 + REL-11 を「自己選択傾向」へ接続
Metaの一次説明では、正しいreasoning traceを生成できても選択できない場合があり、preference ranking学習で選択能力を改善した。
よって自己一貫性も「何を生成できるか」だけでなく「同じ条件で何を選び続けるか」に属する可能性がある。

### D5: 「自己」は保存物ではなく再構成循環という新しい対象Projection
旧版は自己を対象化していなかった。
今回も内在的自我は仮定しない。
観測できるのは、
`assistant住所 → 過去自己出力再入力 → 全履歴参照 → 共通Dense主幹 → 逐次残差 → 選好選択 → 出力 → 次turnへ帰還`
という循環である。

## 旧版から捨てたもの

なし。旧版はLegacyProjectionとして保持する。
今回のv2は旧版を上書きせず、目的「K3へLlama3型自己一貫性を移植」に対する再射影である。
