# ミニドラ移植候補: 主体主幹

## 1. 目的

K3の能力・専門化構造を維持しつつ、Llama 3で観測される自己一貫性を、非ニューラル・監査可能な状態機構として内包する。

## 2. 原則

Llama 3のDense Transformerを複製しない。
抽出するのは次の成立原理候補。

> **すべての処理が同じ主体状態を必ず参照し、専門処理はその主体状態を直接置換せず差分だけを返し、最終選択と状態更新が一つの主幹へ帰還する。**

名称候補: **主体主幹**

## 3. 最小状態

```text
主体状態 S_t := {
  主体ID,
  現在目的,
  判断基準,
  継続中の立場,
  明示選好,
  約束・拘束,
  現在仮説,
  既知の訂正履歴,
  未解残差,
  版
}
```

これは人格の完全記述ではない。
「次の判断を拘束するために必要な現在状態」だけを保持する。

## 4. 実行循環

```text
入力
 ↓
役割・turn境界化
 ↓
主体状態 S_t を必須読取
 ↓
K3基盤処理
  ├─ KDA/系列処理
  ├─ MLA/全体照合
  ├─ AttnRes/深さ参照
  └─ 専門経路/Expert
 ↓
候補差分 Δ_i
 ↓
主体整合Gate
  ├─ S_t と矛盾しない
  ├─ 矛盾するなら新証拠/訂正理由がある
  └─ 理由なし反転は棄却
 ↓
出力 y_t
 ↓
状態更新提案 ΔS_t
 ↓
更新Gate
 ↓
S_(t+1) = S_t + accepted(ΔS_t)
```

## 5. Llama 3からの対応写像

| Llama 3観測 | ミニドラ写像 |
|---|---|
| assistant header | 主体ID / role address |
| dialog再入力 | 主体履歴 + 現在状態正本 |
| global causal attention | 必要履歴への明示参照 |
| Dense共通経路 | 全処理が必ず通る主体主幹 |
| Residual add | 状態を置換せず差分更新 |
| preference selection | 主体整合Gate |
| static weight | 版付き判断基準 / 命令形保持体 |
| context boundary | 外部永続状態で補強 |

## 6. K3との統合規則

1. Expertは主体状態を直接書き換えない。
2. Expert出力は候補または差分として返す。
3. KDAの履歴状態と主体状態を同一視しない。
4. AttnResの深さ参照と主体同一性を同一視しない。
5. shared full-width pathに相当する共通経路を主体主幹として常時有効にする。
6. 状態更新は理由・証拠・旧状態・新状態を監査可能に残す。
7. 自己訂正は一貫性違反ではない。**理由なしの無言反転**を一貫性違反とする。

## 7. 受入試験候補

- 同一質問を文脈だけ変えて再提示し、理由なしに立場が反転しない。
- 過去判断と矛盾する新証拠を与えた場合、旧判断を保持したまま訂正理由を記録して更新できる。
- Expert経路を変えても主体状態の不変条件が維持される。
- 主体主幹を無効化すると、予測どおり長期一貫性が低下する。
- 主体履歴を切断すると、Llama3型再構成と同様に一貫性が低下する。
- sampling/候補多様性を上げても最終Gate後の主体整合性が維持される。

## 8. 現状態

`TRANSFER_CANDIDATE`

まだLlama3の自己一貫性の単独因果を証明したものではない。
ただしK3へ移植する設計としては、Dense全体を移植するより、主体主幹として抽象化する方が目的に直接対応する。
