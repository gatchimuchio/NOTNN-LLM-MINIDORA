# 構文化

`構文化/` は、外部モデル・公開資料・MINIDORA自身をHDS日本語構文で観測・再構成した成果を保持する。

ここは**観測・再構成層**であり、現行Runtime実装や設計正本そのものではない。

## 現行MINIDORAとの関係

- `MINIDORA_v0.5` — 現行実装。厳密LM核と能力模型核を分離。
- `MINIDORA_v0.4/` 以下 — 履歴。無言統合しない。

## 主要観測基盤

- `K3_HDS日本語構文_v2/` — K3観測。今回の再構文化対象外。
- `Llama3_自己一貫性_HDS再構文化_v2/` — Llama 3自己一貫性差分。
- `LLM横断_HDS日本語構文化_相対化ベンチマーク_v0_1/` — 第一巡横断観測。
- `LLM横断_能力成立作用構文化_v1/` — 第二巡履歴。
- `LLM横断_状態差作用構文化_v2/` — K3除外10モデルを状態差・後続依存・経路変化・循環尺度で再構文化した現行横断観測。

## LLM成立規定との責任境界

LLM成立条件の責任正本は `gatchimuchio/LLM-Constitutive-Specification`。

- 版: `2026-08-28-成立規定-7`
- MINIDORA参照commit: `debb83e091a705a5eac09ef4fb97a5b36305db6d`

これは構文化より「上流」という意味ではない。構文化・成立規定・HDS Compiler・MINIDORA・実測は相互に観測を返す循環関係にある。ただし、**何を正本として確定する責任か**は分ける。成立規定はLM成立条件、構文化は観測再構成、設計はMINIDORA契約を担う。

## 取り扱い規則

- 構文化成果を実装へ自動変換しない。
- 観測事実、作用解釈、比較推定、未観測を混同しない。
- Legacy成果を削除せず、現行成果と明示的に分離する。
- HDSによる観測成果であることと、HDS自体がLLM成立条件であることを混同しない。
- `状態が存在する`、`後続へ効く`、`経路が変わる`、`循環する` を別観測とする。
- 現行設計へ採用された内容は `../設計/` 側で契約として明示する。
