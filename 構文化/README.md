# 構文化

`構文化/` は、外部模型・公開資料・MINIDORA自身を日本語意味正本で観測・再構成した成果を保持する。

ここは**観測・再構成層**であり、現行実行系や設計正本そのものではない。

## 言語規定

最上位の言語規定は `gatchimuchio/cognitive-engineering-foundations` に置く。

MINIDORA局所規定は `../設計/00_日本語基底規定_v1.md`。

```text
基本言語・規定言語・構文化言語 = 日本語
外国語 = 実務上必要な外部互換・出典照合だけの例外
```

外部模型の原語体系を内部構文化の主語へしない。

## 成立規定との責任境界

言語模型成立条件の責任正本は `gatchimuchio/LLM-Constitutive-Specification`。

- 版: `2026-08-28-成立規定-7`
- MINIDORA参照commit: `debb83e091a705a5eac09ef4fb97a5b36305db6d`

構文化・成立規定・HDS Compiler・MINIDORA・実測は相互に観測を返す循環関係にある。固定的な一方向上流下流として扱わない。

一方、責任正本は分ける。成立規定は言語模型成立条件、構文化は観測再構成、設計はMINIDORA契約を担う。

## 取り扱い規則

- 構文化成果を実装へ自動変換しない。実装採用時は`設計/`へ契約を置く。
- 観測事実、作用解釈、比較推定、未観測を混同しない。
- 旧成果を削除せず、現行成果と明示的に分離する。
- HDSによる観測成果であることと、HDS自体が言語模型成立条件であることを混同しない。
- `状態が存在する`、`後続へ使われる`、`参照が変わる`、`経路が変わる`、`循環する` を別観測とする。
- 外部原語を内部意味正本へ無言昇格しない。
- 現行設計へ採用された内容は `../設計/` 側で契約として明示する。
