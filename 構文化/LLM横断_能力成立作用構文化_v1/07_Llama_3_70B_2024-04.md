# 07 Llama 3 70B (2024-04) — 能力成立作用構文化

- 観測深度: D3
- 区分: dense global-attention anchor
- ライセンス: CC-BY-4.0

## B0 観測境界

公開config/code/checkpoint構造を観測。hidden 8192、FFN 28672、80 layers、64 Q heads / 8 KV heads、context 8192、vocab 128256。weight全量の意味分布とtraining raw data全量は未観測。

## 観測事実

- decoder-only dense model。
- 全層global causal attention + GQA。
- standard residual stack。
- dense FFN。
- MoEなし。
- 主config上MTPなし。

## B1 状態保持

standard residualは各層で前状態を消して置換するのではなく、前状態へ新しい変換差を加えて後段へ渡す。

### 直接作用

層を進むごとに、それまでの状態差へ新しい関係差を累積できる。少なくともconfig/code上、各層ごとに「採用/廃棄」の離散Gateへ閉じる構造ではない。

## B2 局所更新・参照

局所専用windowは持たない。全層でglobal causal contextを参照するため、近傍も遠距離も同じattention作用の射程内に入る。

## B3 大域再照合

**全層が大域再照合可能な基準点**である。

OLMo/Qwenのような周期的global layerを待たず、各attention層で前方context全体へ再アクセスできる。

## B4 深さ輸送

standard residualにより、各層の変換結果を前状態へ加えて80層に渡し累積する。

### 直接作用

一度得た差が後段で別作用を受ける余地を残す。具体的な概念・仮説がどのhidden directionへ保持されるかは未観測。

## B5 幅選択

Dense FFNなので全tokenが同じ重み集合の変換を通る。expert routingによる条件付き経路選択はない。

### 相対化上の意味

MoEがなくても高能力LLMが成立するため、「専門経路」が一般条件ではないことの基準点になる。

## B6 未確定差の共存

hidden stateは高次元連続状態であり、後段で再加工される。構造上、一つの離散ラベルだけへ早期確定する必要はない。

ここから「複数仮説が明示スロットで保持される」とまでは言わない。言えるのは、**複数の内部差を同時に保持できる表現容量と再作用経路が存在する**ことまで。

## B7 未来補助

主config上、独立MTP層等は観測しない。

## B8 形成作用

pretraining/posttrainingにより、同じDense geometryへ具体的な言語関係・選択傾向が形成される。architectureは作用空間を与えるが、その中身を決めきらない。

## B9 展開後制御

runtime guard、system prompt、tool等はcore外。

## MINIDORAへの作用射影候補

- Data/関係を一回評価して破棄せず、後段で再作用できる中間状態へ残す。
- 同じ元Dataへ複数の関係作用から再アクセスできるようにする。
- 中間状態は単一の「事実採用」集合だけでなく、未確定・弱支持・競合差も保持できるようにする。
- Dense global attentionそのものは不要。必要なのは**後段から再参照可能であること**。
