# 00 統合報告 — K3除外・能力成立作用構文化 v1

- 実施日: 2026-08-26
- 対象: K3を除く10モデル
- 目的: 第一巡の構造観測を、能力成立までの情報作用へ再投影する。
- ライセンス: CC-BY-4.0

## 0. 結論

第二巡で最も重要なのは、**能力は単一部品ではなく、情報差を保持し、何度も再参照・再結合し、最後まで早すぎる確定を避ける作用連鎖として成立する**という点である。

公開weight系6モデルでは実装方式は大きく違うが、共通して「入力差を一回の判定で捨てず、複数段の内部状態変換へ渡す経路」が存在する。

- Llama 3 / K2-V2: 全層global causal attention + residual + dense FFN。
- OLMo 3: 3層のsliding-window参照 + 1層のglobal再照合。
- Qwen3.6: 3層のGated DeltaNet状態更新 + 1層のfull attention再照合 + MoE。
- DeepSeek V4: local detail + compressed long-range参照、複数residual streamのmHC、MoE。
- Apertus 1.5: 中央decoderの系譜を維持しつつ、continued pretraining・multimodal前段・posttrainingで能力を拡張。

この共通性は「Attentionが必要」「MoEが必要」という意味ではない。Llama/K2のDense構造が反例であり、OLMo/Qwenの局所作用子も互いに異なる。共通しているのは、**途中状態を保持し、異なる範囲・段階・作用で再加工できること**である。

閉鎖系4モデルではcore内部を観測できないため、同じ結論を内部architectureへ投影しない。その代わり、能力成立物がweight単体ではないことを強く示す。

- GPT-5.6 Sol: model / inference / agentic harnessを公式に分離。
- Claude Fable/Mythos: 同一underlying modelにclassifier/fallbackを加えるだけで可観測サービス挙動が変わる。
- Gemini 3.x: thinking level、multimodal、tool useを公開するが内部接続方式は非公開。
- Grok 4.6: agent harnessを形成時trajectoryと展開時orchestrationの双方へ利用。

したがってMINIDORAへ必要なのは、既存LLMの部品コピーではなく、**模型中核・形成・外部運用を分離したまま、模型中核側に「未確定差を保持して再作用させる経路」を十分に持たせること**である。

## 1. 第一巡から第二巡への変更

第一巡は主に次を分離した。

```text
系列方向 / 深さ方向 / 幅方向 / 未来補助
モダリティ前段 / 形成 / 展開後制御 / 観測深度
```

第二巡では、それを次の作用へ読み替える。

```text
入力差
↓
状態保持
↓
局所更新・選択参照
↓
大域再照合
↓
深さ方向の累積・混合
↓
幅方向の共通処理・専門処理
↓
未確定差を残したまま再作用
↓
出力に必要な差が形成される
```

ただし全モデルがこの順序・全部品を持つとはしない。例えばLlama 3は局所/大域周期を持たず、全層でglobal参照する。MoEも持たない。よって作用の成立方式は複数ある。

## 3. 横断して見えた能力成立作用

### 3.1 途中状態を捨てない

公開weight系の中央decoderは、一段ごとに「正しい/誤り」を確定して次へ進む構造ではない。

- standard residualは前状態へ新しい変換差を加える。
- mHCは複数streamを維持しながら混合する。
- sliding attentionは局所状態を次層へ渡す。
- Gated DeltaNetは履歴を状態として更新する。
- full attentionは前文脈を再参照する。

ここから直接言えるのは、**途中の情報差に後段で再作用できる経路がある**ことである。

「弱い証拠」「複数仮説」が具体的にどのactivation方向へ符号化されるかまではweight意味未読のため未観測。ただし、構造上はMINIDORA現行のような `採用 / 廃棄` の早期離散化よりはるかに多くの中間状態を維持できる。

### 3.2 局所処理と大域再照合は有力だが普遍条件ではない

OLMo 3とQwen3.6はどちらも3:1周期を持つ。

- OLMo: 3×sliding attention → 1×full attention
- Qwen: 3×Gated DeltaNet → 1×full attention

同じ周期でも作用は違う。OLMoは限定windowを明示参照し、Qwenは圧縮状態を更新する。

一方Llama 3 / K2-V2は全層global attentionで成立する。従って普遍条件は「3:1」でも「局所attention」でもない。

相対化すると重要なのは、**狭い範囲での連続更新と、広い範囲の再接続をどの頻度・方式で行うか**という設計自由度である。

### 3.3 深さ方向は単なる回数ではない

Llama/Qwen/OLMo/Apertus/K2は標準residual系、DeepSeek V4はmHCを持つ。

DeepSeek V4のmHCは複数parallel residual streamを層間で混合し、最後に単一sequenceへ畳む。これはattentionとは別の作用であり、**何を見るか**と**見た差を深さ方向へどう残すか**を分ける必要を示す。

MINIDORAでは「検索できたか」と「検索結果の差を何段保持・再加工できるか」を同一にしない必要がある。

### 3.4 幅方向の専門化は能力の増幅器であって普遍条件ではない

Qwen3.6とDeepSeek V4はMoE、Llama/OLMo/Apertus/K2はDense。

従ってexpert routingはLLM成立条件ではない。ただしMoEでは、共通経路とtokenごとの専門経路を同じ段で並行利用できる。これは「すべての入力へ同じ作用を一律適用する」以外の能力形成方法を示す。

MINIDORAへ射影する場合も、MoEをコピーするのではなく、**共通作用 + 条件付き専門作用**という責任分離として検討すべきである。

### 3.5 形成過程はarchitectureと独立した能力源

最も強い対照はLlama 3とK2-V2である。

両者は hidden 8192 / FFN 28672 / 80 layers / Q64-KV8 のLlama系Dense geometryが非常に近い。一方K2-V2はdomain knowledge、reasoning、long-context、tool useをtraining processへ明示的に注入している。

Apertus 1.0→1.5も同様で、中央decoder architectureを維持しながらcontinued pretraining・multimodal mix・posttrainingで能力を増やす。

Grok 4.6ではさらに、agent harness上のtrajectory自体がSFT/RL形成データへ入る。

したがって、**能力差をarchitectureだけで説明することはできない**。模型側関係の中身はweight/形成履歴にも宿る。

これはMINIDORAにとって重要である。構造を正しく再現しただけでは、既存LLMが形成済みweightへ持つ関係密度・優先度・再結合傾向まで得られない。

### 3.6 展開後制御は能力を見かけ上変える

GPT-5.6とClaude Fable/Mythosが最も強い基準点になる。

- GPT: model、inference、agentic harnessを別層として最適化。
- Claude: 同一underlying modelでもclassifierとfallback先の差でサービス挙動が変わる。

従って外部tool、router、classifier、fallback、cache、multi-agent coordinationを模型中核の能力へ加算しない。

一方、それらが長期課題の完遂性能を実際に増幅することも否定しない。**模型能力とsystem能力を別々に計測する**のが正しい。

## 4. モデル対照から得られた強い自然実験

### Llama 3 ↔ K2-V2

ほぼ同型のDense geometryでもtraining history・context・vocab・posttrainingで能力が変わる。

→ architectureと形成済み関係を分離する。

### OLMo 3 ↔ Qwen3.6

3:1配置周期が同じでも、局所作用はwindow参照とrecurrent/linear状態更新で別物。

→ 配置周期と作用子を分離する。

### Apertus 1.0 ↔ 1.5

中央decoderを維持したままmultimodal、thinking、tool capabilityを拡張。

→ 入力前段・形成・runtime modeを中央geometryから分離する。

### Fable 5 ↔ Mythos 5

同一underlying modelへ外部safeguard/fallbackを付加して可観測挙動が変化。

→ modelとdeployment controlを分離する。

### DeepSeek V4 ↔ standard residual系

系列参照とは独立してdepth transportを変更できる。

→ 参照作用と深さ保持作用を分離する。

## 5. 現行MINIDORA GPQA 9.596%との接続

現行v0.4では外部取得は198/198で空振り0、Data compileも2698/2698成功した。一方、旧v0.6系よりK fact / evidenceが大幅に減り、回答時正答率も16.10%だった。

この実測と本横断構文化を合わせると、優先して再検討すべきなのは次である。

1. **取得Dataを一回のGateで採用/廃棄しすぎていないか。**
2. **未確定関係を中間状態として残し、別Data・別関係と後段で再照合できるか。**
3. **同一証拠を一回だけ評価して終わらず、異なる作用段で再利用できるか。**
4. **局所関係と問題全体の大域関係を別段で再接続しているか。**
5. **候補を一つずつ孤立採点するだけでなく、複数候補の競合差を最後まで保持できるか。**

これらはGPQA専用規則ではない。公開LLMの作用構造を相対化した結果として出た、MINIDORA模型関係側の再監査候補である。

## 6. 普遍化してはいけないもの

次は有効な実装だが、LLM一般条件にはしない。

- Transformer
- Attention
- global attention
- sliding window
- Gated DeltaNet
- MoE
- mHC
- MTP
- multimodal encoder/tokenizer
- RL
- agent harness
- speculative decoding

本第二巡で普遍候補として残るのは部品ではなく、より抽象度の高い次の作用である。

```text
文脈差を内部状態へ保持できる
↓
保持した差へ複数段で再作用できる
↓
異なる範囲・関係の差を再結合できる
↓
未確定差を早期消去せず後段へ渡せる
↓
成立差が十分に形成された時点で出力へ接続できる
```

この作用候補は、次段のMINIDORA再設計で実装形式を別途決める。
