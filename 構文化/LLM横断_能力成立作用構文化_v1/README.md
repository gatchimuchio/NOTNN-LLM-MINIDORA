# LLM横断・能力成立作用構文化 v1

- 実施日: 2026-08-26
- 対象: K3を除く既存横断観測10モデル
- 状態: 第二巡正本
- ライセンス: CC-BY-4.0

## 目的

第一巡 `LLM横断_HDS日本語構文化_相対化ベンチマーク_v0_1` は、系列・深さ・幅・形成・展開後制御などの構造差を分離した。

本第二巡は、その構造をもう一段掘り下げ、**能力が成立するまでに情報へ何が起きるか**を同じ日本語座標で記述する。

部品名を並べることを目的にしない。次を分別する。

1. 観測事実 — 公開weight/config/code、公式model/system card、既存固定観測から直接確認できるもの。
2. 直接作用 — 観測構造から機械的に言える情報操作。
3. 比較推定 — 複数モデルの対照から支持されるが、weight内部意味まで直接読めていないもの。
4. 未観測 — 証拠がなく、埋めないもの。

## 作用座標

- **B0 観測境界** — どこまで内部を直接見たか。
- **B1 状態保持** — 前段の差を後段へ残す経路。
- **B2 局所更新・参照** — 近傍・圧縮状態・限定集合をどう更新/参照するか。
- **B3 大域再照合** — 広い文脈を再接続する経路。
- **B4 深さ輸送** — 層を跨ぐ情報の保持・混合・再利用。
- **B5 幅選択** — Dense / expert routing / shared path等の横方向分岐。
- **B6 未確定差の共存** — 途中差を即時二値化せず残せる構造上の余地。
- **B7 未来補助** — MTP、draft、先読み等。主経路と分離する。
- **B8 形成作用** — pretraining / continued pretraining / SFT / RL / trajectory学習が模型へ残す差。
- **B9 展開後制御** — classifier、fallback、tool orchestration、cache、routing等の模型外作用。

## 成果物

- `00_統合報告.md` — 10モデル横断の結論。
- `01`〜`10` — モデル別作用構文化。
- `11_MINIDORA射影候補.md` — モデル固有部品をコピーせず、作用だけをMINIDORAへ射影する候補。
- `作用相対座標_v1.json` — 機械可読の相対座標。
- `MANIFEST.json` — 対象・境界・状態。

## 禁止

- 閉鎖モデルの内部構造を公開挙動から逆推定しない。
- Attention、MoE、Transformer等の部品名を能力そのものとみなさない。
- benchmark性能から特定内部機構の存在を断定しない。
- K3固有構造をLLM一般条件へ昇格しない。
- 本構文化をそのままMINIDORA実装仕様とみなさない。
