# 11 横断作用差分 — v2

## 相対化の中心

v2では「どの部品があるか」ではなく、**状態差がどの境界で次の計算へ効くか**を比較する。

### 1. 固定stack上の後続依存

Llama 3 / OLMo 3 / Apertus / K2-V2では、residual/hidden stateが後段blockへ渡る。これは強い後続依存だが、それだけでdynamic reactivationとは言わない。

### 2. 状態依存weighting/reference

Attention系ではquery/key/value等が現在stateから形成されるため、同じtopologyでも参照重み・内容はstate依存になる。これはfixed topology内のstate-dependent computationである。

### 3. state-dependent path/reference selection

Qwen3.6のMoE routing、DeepSeek V4のMoE / selected long-range reference、Claudeの外部classifier/fallbackは、状態に応じて実際のpath/reference branchが変わる例。ただしClaudeは模型外。

### 4. recurrent state

Qwen3.6のGated DeltaNet系は、過去を圧縮したstateを系列位置をまたいで更新する。これはfixed-depth residualだけとは別の状態更新型である。

### 5. fixed local/global schedule

OLMo 3とQwen3.6の3:1配置は、局所/圧縮作用とfull attentionを組み合わせる。ただしglobal段の実行自体はscheduleで固定されている。`不一致が出たからglobalが発火` とは観測していない。

### 6. external runtime loop

GPT-5.6 Sol / Grokのagent harness、Claudeのfallback、Geminiのtools/effort controlはsystem能力へ寄与するが、core内部再帰とは分離する。

### 7. formation loop

Grokのtrajectory→SFT/RL、Apertus/K2のcontinued/staged formationは、実行経験・dataが次checkpointへ戻る尺度の循環である。single inference loopではない。

## MINIDORA v0.5の0発火と比較する時の禁止

禁止:

```text
LLMにはresidualがある
→ LLMはcheckpointを再活性する
→ MINIDORA reactivation=0だからそこだけ直せばよい
```

この推論は成立しない。

比較すべきは、

```text
状態Sが作られた
→ Sを消す / 固定する / 置換する
→ 後続作用・参照・routing・結果が変わるか
```

である。能力への実効接続を測る。
