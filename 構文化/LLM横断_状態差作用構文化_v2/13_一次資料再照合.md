## 再照合で確定した主要訂正

1. GPTのagent loopはsystem-levelで明示観測できるが、core内部recurrenceの証拠ではない。
2. Claudeはsame underlying model + external fallbackが一次資料で確認でき、persistent file memoryもsystem-level state依存の自然実験として使える。
3. Geminiはdynamic thinkingを公開しているが、内部で「何回再作用するか」までは公開していない。
4. Qwen/OLMoの周期配置はfixed schedule。状態差によるglobal-layer発火とは扱わない。
5. Llama/K2のresidual stackはdownstream state transport。明示checkpoint再活性とは扱わない。
6. Grokのtrajectory循環はformation loop、Grok Buildのagent loopはdeployment loop。尺度を分離する。
