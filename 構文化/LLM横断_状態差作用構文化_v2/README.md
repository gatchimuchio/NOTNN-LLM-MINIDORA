## v2で変えた観測単位

v1は「状態保持」「再作用可能な経路」を中心に観測した。v2では、それだけでは不十分として次を分ける。

1. **状態担体 S** — 何が後段へ残るか。
2. **作用 A** — その状態へ何をするか。
3. **状態差 Δ** — 作用の前後で何が変化したか。意味内容を読めない場合は表象差としてだけ扱う。
4. **後続依存 D** — Δが後続計算の入力となり、後続結果へ寄与し得るか。
5. **経路変化 P** — Δや現在状態によって、参照先・expert・branch・tool等の選択そのものが変わるか。
6. **再参照 R** — 過去状態または元資料を明示的に再度参照するか。
7. **再結合 C** — 複数の差・stream・参照結果が後段で同一状態へ合流するか。
8. **循環尺度 L** — 深さ方向、系列位置、turn、test-time harness、形成過程を混同しない。

## 用語上の重要な訂正

`後段が前状態を受け取る` ことと `状態差が新しい作用経路を発火させる` ことは同じではない。

- Residual stack: 前状態を後段へ運ぶ。通常はblock配置自体は固定。
- Attention: topologyは固定でも、状態に応じて参照重みは変化する。
- MoE / top-k selector: 状態に応じて実際の経路・参照集合が変わる。
- fixed 3:1 local/global schedule: global再照合の配置は固定であり、状態差による「再活性」とは言わない。
- agent harness loop: 模型外の循環であり、core内部再帰とは言わない。
- trajectory SFT/RL: 形成世代間の循環であり、単一inference内再帰とは言わない。

この区別を崩さないことがv2の主監査条件である。
