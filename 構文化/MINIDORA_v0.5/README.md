## v0.4からの変更

v0.4の候補・関係・証拠評価は能力模型核へ再分類し、厳密言語模型法則とは分離した。v0.5では `src/minidora/言語確率法則.py` を厳密言語模型核として追加した。

```text
厳密言語模型核
完全言語状態空間
+ 持続模型状態
→ 整合した言語確率法則

能力模型核
質問 / 候補 / 資料
→ 関係・証拠・状態差
→ 候補差
```

## v8による能力側の再開放

GPQA実測とK3除外横断構文化v3を受け、能力作用を次の日本語座標で再監査する。

```text
状態担体 / 作用 / 状態差 / 後続利用 /
参照変更 / 経路変更 / 計算量変更 /
再参照 / 再結合 / 循環尺度
```

HDS Compiler Architecture v1.3 / Pipeline v1.4は、このうち `作用→状態差→後続利用` を判断せずに並列成果として保持する。

## 厳密言語模型成立形

- 有限n-gram / finite-state。
- Unicode文字。
- 未観測文字はUNK。
- 厳密 `Fraction`。
- 加算平滑化。
- 終端確率正。
- 保存・復元可能な持続模型状態。
- 無作為抽出非依存。

この方式を言語模型一般の普遍方式へ昇格しない。

## 旧資産

v0.4構成再現、規模測定、GPQA実測、旧HDS接続は削除しない。能力・履歴資料として保持する。
