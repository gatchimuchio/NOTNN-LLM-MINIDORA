# 00 統合報告 — 日本語基底作用構文化 v3

## 0. 結論

K3を除く10模型を日本語意味正本から再構成した結果、v2で一括していた「再作用」は少なくとも次へ分ける必要がある。

```text
1. 状態継承
   前段で生じた状態差が固定された後段作用へ渡る

2. 参照重み変更
   現在状態によって同じ参照構造内の重み・内容が変わる

3. 参照集合変更
   現在状態によって実際に参照する対象集合が変わる

4. 経路選択
   現在状態によって実行する計算経路が変わる

5. 持続状態更新
   系列位置をまたいで圧縮状態を保持・更新する

6. 計算量調整
   入力条件等によって実行時の計算量を変える

7. 外部実行循環
   模型外の実行系が結果を受け、次の作用を選ぶ

8. 形成循環
   実行履歴・学習資料が次の模型形成へ戻る
```

似た現象であっても同一構造ではない。

## 1. 最も強い横断観測

公開内部構造を追える模型群では、ある段で生じた表象差が即座に最終判断へ潰されず、後続計算へ利用可能な形で渡る構造を観測できる。

しかし、ここから次は導かない。

- 全模型が明示中間保存点を再活性する
- 全模型が状態差によって新しい作用を発火する
- 全模型が単回推論内の循環を持つ
- 全模型が条件付き大域再照合を持つ

## 2. MINIDORA v0.5実測との接続

GPQA Diamond 198問の現行実測では、

```text
正答                         = 20 / 198
同一参照資料の比較基準正答     = 22 / 198
中間保存点作成数               = 815
中間保存点再活性数             = 0
大域再照合数                   = 0
候補横断更新数                 = 0
専門作用呼出数                 = 0
```

実装上の元指標名は外部互換・監査用に別資料へ保持する。

この結果から直接言えるのは、**中間保存点を作ることと、その保存状態が後続能力へ実効作用することが分離していた**ということである。

したがって次の比較軸は保存点の存在数だけではない。

```text
状態を除去する
状態を固定する
状態を別状態へ置換する
↓
後続の参照・経路・計算量・候補・出力が変わるか
```

を測る必要がある。

## 3. v2からの主要修正

### 3.1 外部原語を内部概念名にしない

`runtime`、`harness`、`recurrent`、`branch`、`path` 等を内部分類語として使わない。

それぞれ、実行時、外部実行系、持続状態更新、分岐、経路等へ意味分解する。

### 3.2 固定配置と状態依存発火を分ける

OLMo 3およびQwen3.6で観測した局所作用と広域参照作用の周期配置は、配置規則として固定されている。状態差が広域作用を発火するとは扱わない。

### 3.3 深さ方向の状態継承と循環を分ける

Llama 3やK2-V2のような固定層列で前状態が後段へ渡ることを、明示保存点の再活性や単回推論循環と同一視しない。

### 3.4 形成と実行を分ける

Grokで観測される実行履歴→学習→次模型の更新は形成循環であり、単回推論内の循環ではない。

## 4. 現時点の能力作用候補

> **後段能力へ寄与する状態は、単に存在・保存されるだけでは足りず、後続の入力、参照重み、参照集合、経路、計算量、再結合、形成更新のいずれかへ実効的な差を生じさせる位置に接続されている必要がある。**

これは高能力計算の横断観測候補であり、言語模型成立条件ではない。

## 5. 循環再帰への返却

本構文化は構成定義・HDS Compiler・MINIDORAへ命令する上位正本ではない。

一方で、各系へ次の再監査を要求する観測材料になる。

- 状態保存と後続利用を区別しているか
- 作用可能と作用済みを区別しているか
- 参照重み変更と経路変更を混同していないか
- 固定配置と状態差発火を混同していないか
- 形成循環と単回実行を混同していないか
- 外部原語を内部意味正本へ逆流させていないか

どの系が修正されるべきかは先に固定せず、相互実測で再拘束する。
