# 12 MINIDORA実測接続

## 実測

GPQA Diamond 198問、同一参照資料比較:

```text
現行正答                 = 20
比較基準正答             = 22
現行回答数               = 120
比較基準回答数           = 95
中間保存点作成数         = 815
中間保存点再活性数       = 0
大域再照合数             = 0
候補横断更新数           = 0
専門作用呼出数           = 0
```

元実装指標名は監査再現のため別途保持するが、本構文化では日本語概念を正本とする。

## 接続上の重要点

`中間保存点作成数=815` は保存構造の存在を示す。

しかし `中間保存点再活性数=0` であるため、少なくとも当該再活性経路が後続能力へ働いたことは観測できない。

一方、これだけでGPQA低得点の単独原因と断定しない。MINIDORA能力核の他経路が状態依存作用を行っている可能性は別監査である。

次の比較では、

- 状態除去
- 状態固定
- 状態置換
- 参照集合固定
- 経路固定

による後続差を測る。
