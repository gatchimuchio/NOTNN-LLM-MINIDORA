# 11 外部原語対応 — 日本語正本との境界

本書は外部資料照合のための対応表であり、外部原語を内部正本へ昇格させるものではない。

| 外部原語 | 日本語側で分別する観点 |
|---|---|
| state | 状態 / 持続状態 / 作業状態 |
| residual | 残差状態継承 / 差の加算 |
| attention | 参照 / 参照重み / 参照内容 |
| routing | 経路選択 / 参照先選択 / 作用先選択 |
| top-k | 上位候補選択 / 参照集合選択 |
| recurrent | 持続状態更新 / 系列間継承 |
| branch | 分岐 / 経路選択 |
| runtime | 実行時 / 実行系 |
| harness | 外部実行系 |
| loop | 循環 / 反復 / 帰還。どの尺度かを別途明示 |
| checkpoint | 中間保存点 / 中間状態記録 |
| trajectory | 実行履歴 / 実行軌跡 |
| expert | 専門経路。意味専門性は未観測なら付与しない |
| compute effort | 計算量 / 推論量 |
| full attention | 広域参照 |
| sliding attention | 局所参照 |

## 原則

一つの外部語を一つの日本語へ機械置換しない。

`state` のような外部語が複数の日本語差を圧縮している場合、観測対象に応じて日本語側で再分別する。

逆に日本語側で差を確定できない場合は、原語を注記として残したまま内部概念を保留する。
