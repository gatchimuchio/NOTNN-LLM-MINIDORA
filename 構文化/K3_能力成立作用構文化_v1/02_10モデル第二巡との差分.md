# 02 K3とK3以外10モデル第二巡の差分

- 日付: 2026-08-26
- 比較対象: `../LLM横断_能力成立作用構文化_v1/`
- ライセンス: CC-BY-4.0

## 0. 結論

K3は10モデル第二巡で得た共通所見を、最も高い観測深度で同時に実装している基準点になった。

10モデル側で横断的に見えたのは、

- 中間状態を後段まで残す
- 局所更新と大域再照合を分ける
- 深さ輸送と系列参照を分ける
- 共通作用と専門作用を分ける
- architectureと形成済み関係を分ける

という作用だった。

K3ではこれらが同一text core内で明示的に重なる。

## 1. K3 ↔ Qwen3.6

共通:

```text
局所/圧縮更新 ×3
↓
広域attention ×1
```

差:

- Qwen: Gated DeltaNet状態更新 + full attention
- K3: KDA recurrent state + Gated MLA
- K3: さらにAttnResでdepth checkpoint再選択
- K3: 896 experts / 16 routed + 2 shared

意味:

3:1周期が能力本体ではない。同じ周期でも局所state operator、global operator、depth transport、width specializationは別に設計できる。

## 2. K3 ↔ OLMo 3

共通:

- 3局所系 + 1全体参照
- Denseな現在状態を後段へ持ち越す

差:

- OLMo: raw sliding-window attention
- K3: recurrent KDAで圧縮状態更新
- OLMo: standard residual
- K3: AttnRes
- OLMo: Dense FFN
- K3: LatentMoE

意味:

K3は「局所を狭いwindowで見る」のではなく、局所履歴をstateへ織り込み、その後にglobal contextへ戻る。

## 3. K3 ↔ DeepSeek V4

共通:

- 系列方向と深さ方向を分離
- MoEによる専門経路
- 長距離情報を効率化しつつ再利用

差:

- DeepSeek V4: local sliding + CSA/HCA compressed long-range
- K3: KDA recurrent compression + periodic Gated MLA
- DeepSeek V4: mHC multiple parallel residual streams
- K3: AttnRes block checkpoint selection

意味:

深さ方向の情報保持には複数の実装形式がある。

```text
parallel streamを維持する
or
過去blockをcheckpointして必要時に再選択する
```

どちらも「現在stateだけに全情報を押し込めない」点で共通する。

## 4. K3 ↔ Llama 3 / K2-V2

Llama/K2は全層global causal attention + standard residual + Dense FFN。

K3は、

- recurrent KDA
- periodic Gated MLA
- AttnRes
- LatentMoE

へ分解する。

意味:

Llama/K2は単純geometryでも十分な能力を持つためK3方式を普遍条件にはできない。一方K3は、大規模化した状態保持・再作用を計算効率と両立させる一つの極端な実装例になる。

## 5. K3 ↔ Apertus 1.5

共通:

- modality前段とtext coreを分ける
- 中央言語模型へ異種入力を接続する

差:

- Apertusの第二巡では中央decoder系譜維持と形成差が重要
- K3ではMoonViT-V2 + projector + KimiLinear text coreが公開実装として直接追える

意味:

MINIDORAでもmodality固有処理を模型核へ混ぜず、共通内部言語状態へ射影できる。

## 6. K3 ↔ 閉鎖系4モデル

GPT / Claude / Gemini / GrokはD2で、内部weight作用を直接観測できない。

K3はD4で、

- recurrent state
- global attention
- depth checkpoint
- expert routing
- multimodal projection

を実装・weight双方から追える。

従って閉鎖系で可観測な高能力を内部architectureへ逆推定する必要がない。K3が内部作用側の開放基準点になる。

## 7. K3が追加した新しい差分

10モデル第二巡からさらに強くなったのは次の4点。

### 7.1 Gateの再定義

現行MINIDORAではGateが採否境界として強い。

K3ではGateが多くの場合、経路を消すためではなく、寄与を強める / 弱めるために使われる。

これはKDA、MLA output gate、AttnRes、MoEで反復する。

### 7.2 depth checkpointの明示的再利用

10モデル側では「中間stateへ後段から再作用」が共通所見だった。

K3 AttnResでは、12層単位の過去prefixを明示checkpointし、後続layerがlearned weightで選択・混合する。

これは未確定状態の後段再利用を最も直接的に示す。

### 7.3 三軸選択の独立

K3では、

- 時系列stateの選択・更新
- 過去depth stateの選択
- expert widthの選択

が別パラメータで存在する。

一つの万能scoreで全判断を済ませていない。

### 7.4 最終差ができるまで再作用を重ねる

KDA→MLA→AttnRes→MoEは一回きりではなく93層で繰り返される。

したがって能力を「一度の関係抽出で正答を決める」機構へ縮めると、K3の主要作用を失う。

## 8. 横断11モデルで残った一般候補

K3を加えても、次を普遍部品にはできない。

- KDA
- MLA
- AttnRes
- MoE
- Transformer
- Attention
- neural network

一方で11モデル横断後、より強く残る作用候補は、

1. 中間差を保持する。
2. 同一情報へ複数回再作用できる。
3. 局所更新と広域再照合を分離できる。
4. 現在状態以外の過去状態へ戻れる。
5. 共通作用と条件付き専門作用を併用できる。
6. 途中Gateを最終真偽と同一視しない。
7. 最終確定を処理末端まで遅延できる。

である。
